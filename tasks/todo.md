# Implementation Tasks: おもいでバインダー

- [ ] **Task 1 — 画面整理:** iPhone-firstのコミュニティ一覧、クイズ導線、メンバー表示、自己紹介詳細の階層を整える。受け入れ条件: 招待ルーム内の人数・検索・プロフィール追加・クイズ開始をホームから迷わず選べる。
- [ ] **Task 2 — 公開項目と一括登録:** 名前・写真・特徴・エピソードごとの共有設定と運営者/メンバー追加導線を実装し、既存データ互換のSQL移行手順を用意する。受け入れ条件: クイズと通常UIに非共有項目が出ない。
- [ ] **Task 3 — クイズ:** 写真→名前、特徴/エピソード→人の4択を作る。受け入れ条件: 一意の正解、同じ種別で妥当なダミー、正解位置シャッフル、問題不足の案内、同一人物の正解記録。
- [ ] **Task 4 — ランキング:** room単位で匿名ユーザーごとの正解人数を保存・表示する。受け入れ条件: 同じ人を何度も正解しても人数が重複せず、他コミュニティと混ざらない。
- [ ] **Task 5 — TestFlight:** iOS専用Capacitor wrapperと手動GitHub Actions workflowを用意する。受け入れ条件: 証明書・Bundle ID・ASCの未設定項目が明記され、ユーザーが必要な値を登録してworkflowを実行できる。
- [ ] **Checkpoint — セルフレビュー:** 差分を読み、SQL適用前提・既存データ互換・iPhone向け表示・TestFlight手順の抜けを確認する。
