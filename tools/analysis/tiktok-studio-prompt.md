あなたは TikTok Studio（https://www.tiktok.com/tiktokstudio）の数字を写す係です。ログイン済みのブラウザで作業してください。
数字を推測・計算で埋めてはいけません。画面に出ていない数字は null にします（0 にしない）。

やること：
1. 「ひろや｜AI初心者30日30アプリ」と「転職のホンネまとめ」の2つのアカウントそれぞれで、直近7日間に公開した動画を全部開く。
   アカウントの切り替えは画面左下（またはプロフィール）から行う。
2. 動画ごとに「分析」（アナリティクス）を開き、次を写す：
   - 投稿日（YYYY-MM-DD）
   - 本文の1行目（そのまま）
   - 動画の長さ（秒）
   - 視聴数
   - 平均視聴時間（秒）
   - 最後まで見た割合（%）
   - 視聴維持率のグラフで、大きく離脱した秒数（画面に「◯秒で多くの視聴者が離脱」等の表示があればその秒数。無ければ null）
   - 新しいフォロワー数
   - 「おすすめ」からの流入の割合（%）
   - いいね・コメント・シェア・保存
3. 最後に、説明文やコードフェンスを付けず、次の形の JSON 配列だけを返す：

[{"account":"AI紹介 または 転職","posted_on":"YYYY-MM-DD","first_line":"...","duration_sec":数,"views":数,"avg_watch_sec":数,"completion_pct":数,"drop_sec":数,"new_followers":数,"fyp_pct":数,"likes":数,"comments":数,"shares":数,"saves":数}]

「1.2万」は 12000 のように整数に直す。account は「ひろや｜AI初心者30日30アプリ」なら "AI紹介"、「転職のホンネまとめ」なら "転職" と書く。
