## 実施した主な作業

### PR #1 — アフィリエイト運用：ネタ→文案→動画→下書き→受け渡しまでを通す
9コミット・22ファイル・+4900行。この日でいちばん大きいPR。

- **運用アカウント**画面：投稿の系統（企画用／アフィリ用）を分ける単位を、画面から追加・改名・削除
- **投稿文をつくる**画面：ネタを入れると動画の6行と各SNSの本文をまとめて生成し、点検にかけてから出す
- **受け渡し**画面：下書きを、SNSごとに「あとは押すだけ」まで進める
- `lib/draft-rules.js`：嘘を書かせない機械点検（一人称の体験談・出典のない数字・効果の断定・PR表記漏れ）を追加。**プロンプトで頼むだけでは足りないので、生成結果そのものを点検する**
- `lib/handoff.js` + `schema_v4/v5`：SNSを調べ直すと、TikTok（下書き受信箱）・YouTube（非公開）と、**Instagram・Xは「公開しかない」**の2種類に分かれると判明。後者は投稿手前で止める方法が「APIを呼ばないこと」しかないため、許可していないSNSは `post_targets` を `queued` にできないようDBの引き金で止めた
- `schema_v3`：投稿とアカウントに所属を持たせ、またいだ投稿先を作れないようにする
- `lib/llm.js`：`ANTHROPIC_API_KEY` / `OPENAI_API_KEY` のどちらか設定してある方を使う（新規契約なしで済ませるため）
- 動画（縦型16.8秒）とX用画像2枚はブラウザの中で組み立てる。サーバーにffmpegは不要（Vercelの1リクエスト4.5MB制限のため、元々そういう設計）

### PR #6 — TikTok を繋ぐと AI 側が繋ぎ直される不具合を直す（重要）
**実運用で見つかった事故。** TikTok を繋ぐと、別チャンネル（AI初心者側）の
TikTok 連携が**黙って上書きされていた**。

原因：連携先を「同じSNS・同じ表示名なら同じ連携先」とみなして上書きしていたが、
TikTokの表示名は権限次第で取れず、取れないと固定文字列 `TikTok` に落ちる。
2つの別アカウントがどちらも `TikTok` という名前で保存されるため、
2つ目を繋いだ時点で「同じ連携先だ」と誤判定され、1つ目が差し替わっていた。
**連携設定の一覧を見ても TikTok は1行のままなので、気づけない壊れ方だった。**

直し方：表示名ではなく、SNSが発行する変わらないID（TikTokなら`open_id`）で
連携先を見分けるように変更。別チャンネルのものを黙って奪わないよう、
奪おうとしたら断ってどちらのチャンネルの設定を直せばよいか案内する形にした。
テスト187件のうち5件をこの取り違え用に追加し、**見張りを外すと実際に落ちる**
ことも確認した。

### PR #7 — 動画の右を見切れなくし、ハッシュタグを付ける
動画のテキストが右端で見切れる不具合の修正と、ハッシュタグ付与。

### PR #8 — 断りが落ちても下書きで止めない／分析ツールの土台
2つの作業が入っている。

**1. 出典の断りが落ちて予約が止まる問題**：20本まとめて仕込むと、
プロンプトで「出典の断りを必ず入れる」と頼んでいても、書き直し込みでなお
落ちることがあり、そのたびに予約が止まっていた（毎日1本×20日の運用が途切れる）。
「頼むのではなく、無ければこちらで足す」方式に変更。足した一文
（「ネットで見かけた声を集めたものです」）は運用者に実体験が無いという
誰が書いても変わらない事実なので、足しても嘘にならない。**黙っては足さず**、
足したことをグレーの指摘として画面に出す。

**2. 分析ツールの土台**：`schema_v8_insights.sql` で数字をためる場所を作った。
SNSのAPIは「いまの値」しか返さないため、毎日書き留めないと伸びが分からない。
同じ日の2回目は上書き、取れなかった日も理由つきで残す、TikTokの動画は
別表にして投稿と結びつけない（結びつけると誤った組み合わせで「この台本が
伸びた」と誤読しかねないため）。`lib/advice.js` で「言えることだけ言う」
仕組み（中央値で比較、本数が足りなければ断る）も追加。

`lib/insights.js` はSonnetに実装を渡し、実際にありそうな壊れ方を6通り
投げて検証。**その過程で `lib/advice.js` の文言の誤りが見つかった**
（YouTubeは権限があっても登録者数を非公開設定にしていると返ってこないのに、
「権限が足りていない可能性が高い」と言っていた＝直しに行っても直らない指示）。
