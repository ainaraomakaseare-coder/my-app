## 実施した主な作業（すべて本番に反映。PR #58 はマージ待ち）

### 1. TikTok の直接投稿（PR #52）
- 連携に `video.publish` があり、投稿に本人が選んだ設定があるときだけ直接投稿。無ければ下書き送信
- TikTok の決まりどおりの投稿設定（公開範囲に既定値なし・操作は最初は外す・商用申告・指定の同意文）
- 審査前で断られたら、動画を送る前に下書き送信へ自動で切り替え
- 公開後の動画ID（19桁）を丸めずに保存（JSON の数値で読むと末尾が変わる）
- `schema_v9_tiktok_direct.sql`

### 2. 連携が切れる件（PR #52・#58）
- 取り直す前に DB の最新の引換券を読む。TikTok と X は取り直すたびに券が替わるため
- 取り直しに失敗したら、理由を連携設定に「切れています」として出す
- YouTube は Google Cloud の同意画面が「テスト中」で、7日で切れる仕様だった → 本番に公開
- X への同じ対策は PR #58（マージ待ち）

### 3. X（課金して接続）
- X Developer で開発者登録・$5 のクレジット購入・OAuth 2.0 の設定・接続・試し投稿まで成功

### 4. Threads（PR #53）
- OAuth（短期 → 60日の長期トークン、切れる前に自動で延長）・投稿（文字・画像・動画）・数字の取り込み
- `schema_v10_threads.sql`
- **連携後、Threads のアカウントが凍結された**。本人が異議申し立て済み。結果が出るまで Threads は止める

### 5. AI の投稿案をまとめて貼る（PR #54・#58）
- 見出しで切って各SNSの欄へ。文章は書き換えない
- X の文字数を X の数え方（日本語1文字＝2）で見る。280を超えたら保存時にも止める
- チャット画面からコピーして「##」が落ちた見出しを拾えず、YouTube の文が TikTok に混ざっていた → PR #58 で修正

### 6. 企画の型と毎日の記録（PR #55）
- 運用アカウントごとに企画の型（書き方・締めの一言・固定タグ・開始日・期限・目標金額・売上の内訳）
- 毎日の記録：売上の内訳・かかったお金・作業と時間（人間／AI）・作ったアカウント・公開したサービス・学び
- 数字（DAY・累計・利益・あと○円・達成率・残り日数・作業時間）は記録から計算し、AI には差し込み口だけを書かせる。
  AI が数字を書いた・「誰でも稼げる」と約束したら点検で止めて書き直させる
- `schema_v11_series.sql`

### 7. 動画づくり（リポジトリの外：`C:\Users\清水皓也\video-tools`）
- ffmpeg を導入。文字起こしは Node の transformers.js（Whisper large-v3-turbo の軽量版）
- DAY29 を元の素材から作り直し（テイク選び・縦切り抜き・説明カード・字幕・テロップ）

## 発生したエラー・つまずき

| つまずき | 原因 | 対処 |
|---|---|---|
| ffmpeg 内蔵の文字起こしが30秒に9分、しかも文字化け | このPCは Windows on ARM（Snapdragon）。x64 版をエミュレーションで動かしていた | ARM でそのまま動く Node の文字起こしに切り替え。108秒の音声を26秒で処理 |
| モデルの置き場所が作れない（EPERM） | 日本語のフォルダ名が URL のまま %E6… に化けた | `fileURLToPath` で戻す |
| Supabase のエディタに文字を打てない | ブラウザの自動操作とエディタの相性 | 本人に Run してもらった |
| Meta のリダイレクトURIが保存できない | 欄に貼っただけでは登録にならない（確定の操作が要る） | 貼り直して確定 |
| Threads の接続で「URLはブロックされています」 | 登録したコールバックURLとアプリが送ったURLの不一致 | 登録し直して接続 |
| X の許可画面で Something went wrong | 「I trust this app」の確認の前に進めた可能性 | 確認を入れて許可 → 接続 |
| まとめて貼ると YouTube の文が TikTok に入る | 「##」が落ちたかっこ付き見出しを見出しと判定できなかった | 修正・再現テスト追加（PR #58） |
| 開始日より前に「DAY-5」と出る | 開始前を考えていなかった | 開始前は「開始まであと○日」 |
| X・YouTube・TikTok の連携が同時に切れた | **原因不明**（記録する前に繋ぎ直したため） | 次に切れたら連携設定の理由を見る |
