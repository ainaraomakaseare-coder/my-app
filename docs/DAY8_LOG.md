## 発生したエラー・つまずき

### 1. X の無料枠が消えていた（調査段階）

当初「テキスト投稿が一番簡単な X」を第一候補にしていたが、調べたところ **2026年2月に無料枠が廃止され従量課金に移行**していた。複数の情報源が一致したため候補から外した。
→ **未解決の確認事項**：開発環境から `docs.x.com` に接続できず、X の公式ドキュメントでの裏取りができていない。X を使う日が来たら、開発者ポータルの料金画面を自分の目で確認する必要がある。

### 2. 開発コンテナから Instagram API に到達できない

`graph.instagram.com` への通信がネットワーク制限でブロックされた（curl は接続不可、Node の fetch は 403）。
→ **実際のAPI通信の検証は ainaraさんのPC上でしか行えない**。そのため、AI側では通信部分を偽物に差し替えたテストを19項目用意し、「API を呼ぶ手前まで」の正しさを保証する形にした。

### 3. Instagram はファイルを直接受け取らない（仕様の壁）

画像・動画を送るのではなく「インターネット上の公開URL」を渡し、Meta 側が取りに来る仕様だった。ローカルアプリなのに外から見える置き場所が要る、という矛盾が発生。
→ Cloudflare Tunnel で一時的な公開URLを作って解決。

### 4. トンネルがセキュリティ穴になりかけた

3の解決策をそのまま適用すると、アプリ全体がインターネットに晒され、URLを知った人が誰でも投稿・削除できてしまう。
→ **メディア配信専用の読み取り専用サーバーを別ポートに立て、トンネルはそちらにだけ繋ぐ**設計に変更。`/media/` 以外は 404、GET と HEAD 以外は 405、`..` を含むパスは拒否。テストで確認済み。

### 5. OAuth の往復を今日は実装しないと判断

正式な OAuth は「許可画面から戻ってくるURL」を Meta 側に事前登録する必要があるが、Cloudflare Tunnel のURLは起動のたびに変わるため、毎回登録し直しになる。
→ 今日は Meta 管理画面でトークンを発行 → アプリが自動で長期トークンへ交換、という方式にした。交換処理は本物のAPI通信なので、OAuth の核心（短期／長期トークン）は体験できる。

### 6. 開発環境で Playwright のブラウザ版が合わなかった

`npx playwright install` は禁止されている環境で、インストール済みの Chromium とバージョンが食い違いエラー。
→ `executablePath` で既存の Chromium を直接指定して解決。

### 7. Windows と Mac でコマンドが違った

手順を `cp .env.example .env` で案内したが、Windows のコマンドプロンプトに `cp` は無い。
→ `copy` に読み替え。以降 `ls`→`dir`、`cat`→`type` の対応表を渡した。

### 8. 別のリポジトリで作業を始めていた

Day7 のフォルダ（day07-soccer-attendance）で `git pull` していた。今日のアプリは別リポジトリの別ブランチにある。
→ `git clone` してから `git checkout claude/sns-bulk-post-manager-j64x4q` で解決。

### 9. Instagramテスター招待が見つからない

Meta 側では「承認待ち」になっているのに、Instagram のブラウザ画面には「アクティブなアプリはありません」としか出なかった。招待は別タブにある。
→ PC のブラウザから承認できた。

### 10. トンネルのトップページが文字化けした

メディア専用サーバーが返す日本語メッセージに `charset=utf-8` を書いていなかったため、日本語版 Windows のブラウザが別の文字コードで解釈して化けた。
→ レスポンスヘッダーに charset を追加（コミット 752dbcb）。なお化けていた文面自体は「このサーバーはメディアしか配りません」という想定どおりの応答で、**トンネルが通っている証拠**だった。

### 11. 公開URL未設定のまま投稿ボタンを押した

エラーメッセージが「cloudflared でトンネルを開き、そのURLを登録してください」と次の手順まで示したため、詰まらずに復帰できた。エラー文言を作り込んでおいた効果が出た場面。

## 途中で出た設計上の宿題（DAY9以降の候補）

1. **手動投稿がアプリに記録されない** — Instagram アプリから直接出した投稿はアプリ側に残らず、台帳と実態がズレていく。`GET /me/media` で取り込んで同期する必要がある（`instagram_business_basic` で取れるはずだが未検証）。
2. **分析** — いいね数・コメント数は現在の権限で取れる可能性があるが未検証。リーチ・保存・フォロワー推移は `instagram_business_manage_insights` が必要で、権限画面では「アプリレビューに追加」＝**審査が必要**と表示されていた。
3. **無人での予約投稿** — 現状は PC とアプリとトンネルが動いている間だけ。常時稼働にはクラウドへの引っ越しが必要（その場合 cloudflared は不要になり、URLが変わる問題も消える）。
4. **長期トークンの自動更新** — 60日で切れる。今は手動ボタン。
5. **他SNSへの展開** — YouTube は無料・審査なしで実装可能。TikTok は審査2〜4週間。X は従量課金。

**順番としては「同期 → 分析」**。同期していない状態で分析しても、アプリ経由の投稿だけの数字になり実態と合わない。
