# DAY12 計画 — アフィリエイト企画の立ち上げ

> DAY11 で作った「投稿卓 NEO」を、**別アカウント運用で実際に使う**日。
> DAY11 の複数アカウント対応は実装・テスト済みなので、**繋ぐだけで動く**状態。

## この日のゴール

```
A8.net に登録
  ↓
案件を選ぶ
  ↓
動画を作る
  ↓
投稿卓NEO に登録（アフィリ用アカウント宛て）
  ↓
指定時刻に自動投稿
```

## 調べて分かっている前提

| 事実 | 影響 |
|---|---|
| A8.net は**サイトが無くてもSNSアカウントで登録できる** | ブログを作る必要はない |
| 掲載できるのは **Instagram / YouTube / TikTok / Pinterest** | **X は対象外。アフィリ用途でXは使えない** |
| 広告を載せるSNSアカウントは、**主サイトか副サイトとして事前登録**が必要 | 先にアカウントを用意しておく |
| 登録には**審査がある**（即日とは限らない） | **前日までに申し込んでおくべき** |

**→ X の $5 チャージは、アフィリ目的なら不要。** 企画アカウント側で使いたくなったときに判断すればよい。

## 前日までにやっておくこと（待ち時間があるもの）

**この3つは当日やると詰まる。**

### 1. A8.net に登録申請 ★最優先
- サイト不要。**Instagram / YouTube / TikTok / Pinterest のいずれかのアカウント**で申請
- **審査に日数がかかる可能性がある**ので、当日の朝では間に合わないおそれ
- どのアカウントを媒体として登録するかを先に決めておく

### 2. アフィリ用アカウントの準備
- そのアカウントを**プロアカウント（ビジネス／クリエイター）**にする（Instagramの場合）
- **Metaアプリ `toukoutaku` の Instagramテスターとして追加 → そのアカウント側で承認**
  - DAY8 で「招待が見つからない」で詰まった箇所。PCのブラウザから承認する

### 3. TikTok を使うなら、`client_key` の修正
- DAY11 で止まったところ。**Sandbox の鍵**（Production のものではない）を使う

## 当日の流れ

| # | 内容 | 目安 |
|---|---|---|
| 1 | A8.net で案件を選ぶ（審査が通っている前提） | 30分 |
| 2 | 提携申請 → 承認（即時提携の案件を選ぶと早い） | 15分 |
| 3 | 動画を作る | **ここが一番読めない** |
| 4 | 投稿卓NEO の連携設定に、アフィリ用アカウントを追加 | 10分 |
| 5 | 投稿を登録し、投稿先を**アフィリ用アカウントだけ**に絞る | 5分 |
| 6 | 予約 → PCを閉じる → 自動投稿を確認 | 10分 |

## 想定される壁

| # | 壁 | 対策 |
|---|---|---|
| 1 | **A8.netの審査が当日までに通らない** | 前日までに申請。通らなければ「審査待ちも含めて記録する」回にする |
| 2 | **Instagramのキャプションのリンクはタップできない** | 導線はプロフィールのリンクか、ストーリーズ。**アフィリ設計の根本に関わるので先に決める** |
| 3 | **案件ごとに掲載ルールが違う**（SNS不可の案件もある） | 提携前に「SNS掲載可」を確認する |
| 4 | **動画制作に時間を持っていかれる** | 案件選定と投稿の仕組みを先に通し、動画は短いもので一度通す |
| 5 | 企画用アカウントに誤爆 | 投稿先のチェックを**アフィリ用だけ**にする。画面で名前が出るので確認しやすい |

## DAY11 の資産で効くもの

- **複数アカウント対応**（実装・テスト済み）— アフィリ用を足すだけ
- **投稿先の名前表示** — `Instagram（アフィリ用）` と出るので誤爆しにくい
- **アカウント単位の成否と再実行** — 片方だけ失敗しても、そこだけやり直せる
- **PCを閉じても動く** — 投稿時刻を最適な時間帯に置ける
