# ドラマ王 AI作成問題台帳

17作品それぞれ20問、合計340問を作り置きするための確認台帳です。

AIが書いた時点では公開せず、次の条件を満たした問題だけ `apps/day05-dramaou/index.html` の `BAKED` に入れます。

1. 正解を外部資料で確認できる
2. 正解が一意に決まる
3. 4つの選択肢が同じ種類・粒度になっている
4. 正解だけが長さや表現で目立たない
5. 同じ事実を言い換えただけの重複問題ではない
6. 作品やシーズンの違いを問題文で区別できる

## 問題ごとに残す情報

- 問題文
- 正解
- ダミー選択肢3つ
- 難易度（1〜3）
- 解説
- 根拠URL
- 確認日
- 対象シーズン・版

## 今回の確認方法

- Wikipedia日本語版の対象記事から、人物・各話・記事本文に直接書かれている事実を候補として収集
- AIが候補を「設定・人物・出来事・各話」に分け、不自然な空欄、重複、端役だけの問題を除外
- 「逃げるは恥だが役に立つ」は[TBS公式・第1話あらすじ](https://www.tbs.co.jp/NIGEHAJI_tbs/story/story01.html)を中心に補完
- 「JIN-仁-」は[TBS公式・2009年版](https://www.tbs.co.jp/jin2009/)の人物・各話情報を中心に補完
- 「LIAR GAME」は[フジテレビ公式・第1話あらすじ](https://www.fujitv.co.jp/b_hp/liargame/backnumber/707000003-1.html)で基本設定を確認
- 「プロポーズ大作戦」は[フジテレビ公式・各話一覧](https://www.fujitv.co.jp/b_hp/propose/backnumber/list.html)で各話情報を確認
- 340問すべてを、正解一意性・四択重複・正解の長さ・問題文重複の機械検査に通す
