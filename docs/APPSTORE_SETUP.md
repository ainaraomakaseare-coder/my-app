# アプリのダウンロード数を投稿卓に出す（App Store Connect の鍵の入れ方）

投稿卓の「のび」画面の一番上に、iOS アプリごとのダウンロード数（累計・最新の日・直近7日）が出ます。
数字は Apple の「売上とトレンド」から毎回取ります（追加のお金はかかりません）。

**鍵（.p8 の中身・キーID・発行者ID）はチャットにも GitHub にも貼らないでください。Vercel にだけ入れます。**

## 1. App Store Connect でキーを作る（1回だけ）

1. https://appstoreconnect.apple.com →「ユーザとアクセス」→ 上のタブ「統合」
2. 左の「App Store Connect API」→「チームキー」→「＋」（初めてならアクセスのリクエストが出るので許可する）
3. 名前は「投稿卓」など。**アクセス（役割）は「Sales」**を選んで「生成」
4. できた行の「API キーをダウンロード」で `AuthKey_XXXXXXXX.p8` を保存（**ダウンロードは1回しかできません**）
5. 同じ画面の **キーID**（その行）と、表の上にある **Issuer ID（発行者ID）** を控える
6. 「支払いと財務レポート」を開き、左上に出ている **ベンダー番号**（8で始まる数字）を控える

## 2. Vercel に入れる

Vercel → 投稿卓のプロジェクト → Settings → Environment Variables で、次の4つを足す（Production）。

| 名前 | 入れるもの |
|---|---|
| `ASC_KEY_ID` | キーID |
| `ASC_ISSUER_ID` | Issuer ID（発行者ID） |
| `ASC_PRIVATE_KEY` | .p8 をメモ帳で開いて、`-----BEGIN PRIVATE KEY-----` から最後の行まで全部 |
| `ASC_VENDOR_NUMBER` | ベンダー番号 |

入れたら Deployments → 最新の「…」→ Redeploy。

## 3. 確かめる

投稿卓 →「のび」→「アプリのダウンロード数」に表が出れば完了。
「動画用にコピー」で、動画の報告に使える文がコピーされます。

うまくいかないとき：
- 「401：鍵が違います」… 3つ（キーID・Issuer ID・.p8）が同じキーのものか
- 「403」… キーの役割が Sales（または Finance・Admin）になっているか
- 「ベンダー番号」… `ASC_VENDOR_NUMBER` の数字

## 数え方

- App Store Connect の「売上とトレンド」の「ユニット数」と同じ（新規ダウンロードだけ）。再ダウンロード・アップデート・TestFlight は入りません
- アナリティクスの「初回ダウンロード数」とは少しずれることがあります
- Apple の数字は1日ほど遅れて出ます。まだ出ていない日は「まだ」と表示します（0件とは区別）
- 累計は直近12か月ぶん（アプリはすべてこの1年以内に公開）
