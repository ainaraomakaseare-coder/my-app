## リポジトリの決めごと

アプリはひとつずつ別のリポジトリに作り、記録はこの管理リポジトリに集約します。新しいアプリのリポジトリ名は **`dayNN-アプリ名`**（例：`day04-blackjack`）。DAY3 だけは企画の途中で決めた方針より前に作ったため `my-app` のままです。

DAY1・DAY2・DAY4・DAY5 はまだリポジトリに載っていません。**この片付けが DAY6 の課題のひとつ**です（下記）。名前は `day01-kujibiki` / `day02-millionaire` / `day04-blackjack` / `day05-dramaou` を想定。

新しいリポジトリには `templates/app-repo-CLAUDE.md` を `CLAUDE.md` として置きます。これで、そのリポジトリで作業する Claude が「ログはここに書かない」と分かります。

## DAY6 でやる片付け

ここまでの5日分のアプリが、PCのフォルダとGitHubにばらばらに散らばっている。DAY6 は人狼アプリの公開と合わせて、この状態を整理するのが学びのひとつ。

- 1アプリ1リポジトリに揃える（`dayNN-アプリ名`）
- DAY1・2・4・5 のコードを、それぞれのリポジトリに載せる
- 各リポジトリに `templates/app-repo-CLAUDE.md` を `CLAUDE.md` として置く
- 記録はこの管理リポジトリだけに集める
- DAY4・DAY5 のログをさかのぼって書く

動画の切り口：「アプリ5個作ったんですが、どこに何があるか分からなくなりました。」
