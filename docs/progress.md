## リポジトリの決めごと

アプリはひとつずつ別のリポジトリに作り、記録はこの管理リポジトリに集約します。新しいアプリのリポジトリ名は **`dayNN-アプリ名`**（例：`day04-blackjack`）。DAY3 だけは企画の途中で決めた方針より前に作ったため `my-app` のままです。

DAY1・DAY2 はリポジトリに載っていません。DAY3・4・5 は `my-app` の中に入っていますが、**別リポジトリではなく合流していないブランチ**として積み上がっています。**この片付けが DAY6 の課題のひとつ**です（下記）。新しい名前は `day01-kujibiki` / `day02-millionaire` / `day03-chinchiro` / `day04-blackjack` / `day05-dramaou` を想定。

新しいリポジトリには `templates/app-repo/` の中身をコピーします。`CLAUDE.md`（ログはここに書かない、と伝えるもの）と、時間を自動記録する `.claude/` が入っています。

## DAY6 でやる片付け

ここまでの5日分のアプリの置き場所が崩れている。DAY6 は人狼アプリの公開と合わせて、これを整理するのが学びのひとつ。

**今の状態**（2026-08-26 時点で確認）

`my-app` には **main ブランチが無く**、合流していない `claude/*` ブランチが4本あるだけ。しかもDAY3・4・5 のアプリが全部この1つのリポジトリに入っていて、それぞれ前のアプリのコミットの上に積み上がっている。ブラックジャックのブランチにはチンチロの `index.html` も一緒に載っている状態。DAY1・DAY2 はそもそもリポジトリに無い。

| ブランチ | 中身 |
|---|---|
| `claude/consultation-f97x8e` | チンチロ（DAY3） |
| `claude/blackjack-game-dev-1wvcdm` | ブラックジャック（DAY4）＋チンチロ |
| `claude/drama-quiz-app-7kzkkq` | ドラマ検定（DAY5）＋チンチロ |
| `claude/30days-30apps-handoff-q8l4k9` | この docs |

**やること**

- 管理リポジトリ `30days-30apps` を作り、この `docs/` を移す
- アプリごとにリポジトリを分ける（`dayNN-アプリ名`）。各ブランチから、そのアプリのファイルだけを取り出して移す
- 各リポジトリに main ブランチを作る。合流していないブランチだけ、という状態をやめる
- DAY1・DAY2 のコードが手元にあれば、それぞれのリポジトリに載せる
- 各リポジトリに `templates/app-repo/` の中身（`CLAUDE.md` と `.claude/`）を置く
- 記録はこの管理リポジトリだけに集める
- DAY4・DAY5 のログをさかのぼって書く

**注意**：ブランチを消す前に、各アプリのファイルが新しいリポジトリに入って動くことを確認すること。消すのは最後。

動画の切り口：「アプリ5個作ったんですが、どこに何があるか分からなくなりました。」
