## リポジトリの決めごと

**DAY6 で方針を変えました。** 当初は「アプリはひとつずつ別のリポジトリに作る」でしたが、作業環境の権限で新規リポジトリを作成できなかったため（`403 Resource not accessible by integration`）、**1つのリポジトリ `my-app` の中で `apps/dayNN-アプリ名/` に分ける**形にしました。

```
my-app/
  index.html            全アプリへのトップページ
  apps/dayNN-アプリ名/  各日のアプリ（1アプリ1フォルダ）
  docs/                 企画のルール・ロードマップ・日次ログ
```

記録は今までどおり `docs/logs/dayNN.md` に集約します。アプリのフォルダには置きません。

将来リポジトリを分けられるようになったときのために `templates/app-repo-CLAUDE.md` は残してあります。分けるときは各リポジトリの `CLAUDE.md` として置いてください。

DAY1（くじ引き）と DAY2（ミリオネア）はまだ入っていません。手元にコードがあれば `apps/day01-kujibiki/` `apps/day02-millionaire/` として追加してください。

## リポジトリに入れた Skill（DAY10）

`.claude/skills/quiz-design/` に「クイズの出題設計」を Skill として置きました。**Claude がクイズの話をしているときに自動で読みます。** 中身は、出題を出す前の4つの検査・ダミー選択肢の作り方・難易度の層の持ち方・AIに問題を作らせるときの作法と、検査を機械で回すスクリプトです。

DAY2 のミリオネアも DAY5 のドラマ王もクイズなので、この先クイズを作るたびに効きます。実際、DAY10 でこの Skill をドラマ王に当てたところ、**同じ言い回しの設問が4問並んでいたこと**と、**内訳の帯が一度も伸びていなかったこと**が見つかりました。Skill には、今回うまくいった「AIを使わずに地の文から中身を問う」やり方も書き足してあります。
