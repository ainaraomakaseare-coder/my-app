## エラー・つまずき

- **GitHub のリポジトリを Claude 側から作れなかった。** `create_repository` が
  `403 Resource not accessible by integration` で失敗。連携している GitHub App に
  リポジトリ作成の権限が無いため。→ 人間が GitHub の画面で作る必要がある。
- **`timelog.js mark` を手で叩くと固まる。** フックは Claude Code が stdin に JSON を
  流す前提で `readStdin()` が入っており、手動実行では入力待ちのまま止まる。
  → `node .claude/hooks/timelog.js mark start < /dev/null` で回避。
- **コンテナの時計が UTC だった。** そのまま記録すると日付が1日ずれる（JST 8/27 朝 = UTC 8/26 夜）。
  → `TZ=Asia/Tokyo` を付けて実行。
