## 実施作業

- 16:26 ログ開始。`handoff.md` §14 の方針どおり、まずターゲットと悩みのヒアリングから始める

**1. 先にヒアリングした**

LPは「誰に、何をしてほしいか」が決まらないと1行も書けません。作り始める前に4つ決めました。

| | 決めたこと |
|---|---|
| 目的 | ドラマ検定を遊んでもらう（売るのではない） |
| ターゲット | ドラマ好きの一般の人 |
| 置き場所 | `apps/day11-lp/` |
| 見た目 | アプリに揃える |

**2. アプリの現状を確認してから書いた**

DAY10 の後半でアプリの見た目が大きく変わっていた（Slack風のワークスペース）ので、記憶で書かずに実物をスクリーンショットで確認しました。載せる数字もすべてコードから取り出しています（17作品・340問・10問・称号6段階）。手で書き写すとずれるためです。

**3. 構成を決めて書いた**

ヒーロー → 作品の帯 → あるある → 3ステップ → 称号 → 作品と数字 → 問題の質 → 最後のCTA。CTAは3か所に置きました。

**4. 実物の画面写真を入れた**

最初に書いたLPにはアプリの画像が1枚もなく、何のサイトか伝わりませんでした。実際にアプリを動かして出題画面と結果画面を撮り、ヒーローと称号の節に入れました。作り込んだモックではありません。

撮り直す手順：`apps/day05-dramaou/index.html` をローカルで配信し、Wikipedia への通信だけ差し替えて Playwright で `#scr-quiz` と `#scr-done .scorebox` を撮る。スクリプトは使い捨てなのでリポジトリには置いていません。


## エラー・つまずき

- **アプリの見た目が記憶と違っていた。** DAY10 の後半に別のエージェントが Slack 風のUIへ作り替えていて、以前の「墨に金」の配色ではなくなっていた。記憶のまま書いていたら、LPとアプリで別物になっていた
- **最初のLPにアプリの画像が1枚もなかった。** 文字だけで「10問のクイズです」と説明しても、何が出るのか伝わらない
- **見出しが「覚えて／る？」で改行されて間が抜けた。** 文字サイズと段組みの幅が合っていなかった

## 解決方法

- 書き始める前にアプリをブラウザで開いてスクリーンショットを撮り、配色をコードから読み直した
- 実際にアプリを動かして出題画面と結果画面を撮り、ヒーローと称号の節に入れた
- 見出しの最大サイズを下げて、2段組みの幅に収まるようにした。コピーも1文字短くした
- **アプリ側にあるチャンネル一覧やDM風の造作は、LPには持ち込まなかった。** アプリの中の演出としては成立するが、宣伝ページで同じことをすると別のサービスの公式ページに見えてしまうため

## 今日できるようになったこと

- 作る前に「誰に、何をしてほしいか」を決めてから書く
- アプリの実物を確認してから宣伝を書く（記憶で書かない）
- 載せる数字をコードから取り出して、書き写しのずれをなくす
- 実際に動かした画面を撮って、宣伝ページに使う

## 今日の動画で使えるポイント

1. **AIにLPを作らせる前に、AIから質問させた。** 「誰に、何をしてほしいか」が決まらないとコピーは書けない。いきなり「LP作って」ではなく、先に4つ答えるところから始めた
2. **最初のLPにはアプリの画像が1枚もなかった。** 文字だけでは何のサイトか伝わらない。実際に動かして撮った1枚を入れただけで、説得力がまるで変わる
3. **記憶で書くと、アプリと宣伝が別物になる。** 前回の後半でアプリの見た目が変わっていたことに、実物を見て気づいた。宣伝を書く前に、売るものを見に行く
