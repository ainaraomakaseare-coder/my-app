# ごはんの足跡：テレビで紹介された店と、行きたい場所のリスト

**新しい挑戦**：テレビで紹介されたお店を「番組の映像は使わず、事実（店名・住所・放送日）と出どころのリンクだけ」で集め、地図で探して食べた記録につなげる

## 実施作業

- 別の場所でやったテレビグルメのライバル調査（「番組をまたいで近くのテレビの店を地図で探し、行った記録を残す」はどこもやっていない）を受けて、ごはんの足跡の機能案をClaude Docにまとめ、3段階のうち第1段階（0円）で始めることを決めてもらった
- 「番組だけでなく、行きたい場所のリストも一覧や地図にしたい」という追加の要望を受け、テレビの店とは別に、自由に足せる「行きたい」タブを作った
- 「テレビ」タブ：`tv-shops.json`（同梱）を番組で絞り込み・近い順・地図で見る。詳細に番組名・放送日・番組の公式情報とお店の公式リンク
- 「行った記録をつける」：お店の名前と位置を入れた記録フォームを開き、保存するとお店の詳細に戻って「行った記録（1回）」が出る
- 行ったかどうかは記録の「お店」の名前（どちらかに含まれる）か、お店の名前の無い記録なら40m以内で判定
- 地図は旅の足跡と同じLeaflet＋OpenStreetMap（地図を開いたときだけ読み込む）。iPhoneアプリにも同梱
- 書き出し・読み込みに行きたい場所を含めた。プライバシーポリシーに送る情報（検索した文字・お店の住所）を追記
- 最初の1店は、ユーザーがテレビ画面を撮って送ってくれた「らぁめん千寿 御徒町店」（フジテレビ「かまいまち」2026-10-29放送の山手線売り切れグルメSP）。番組表（Gガイド）と地域ニュースの住所で確かめた

## エラー・つまずき

- 開発環境から国土地理院・OpenStreetMap・番組の公式サイトに通信できず、お店の緯度・経度をリストに入れられなかった
- テレビ東京の孤独のグルメの公式ページは店名と地域までで、番地が無い回が多かった

## 解決方法

- 位置の無いお店は、アプリが住所から位置を調べて端末に覚える形にした（実ブラウザのテストでは国土地理院の応答を差し替えて確認。本物への通信は未確認）
- 店のリストは無理に増やさず、確かめられた1店だけで始め、どの番組・地域を足すかをユーザーに聞くことにした

## 今日できるようになったこと

- 著作権の心配がある情報（番組の映像）を使わずに、事実と出どころのリンクだけで「テレビで紹介された店」の機能を作る
- 1つのアプリに地図・一覧の切り替えと、記録との自動の突き合わせを入れる

## 今日の動画で使えるポイント

1. テレビ画面を撮った写真のテロップ（駅名・店名）から、番組と店を突き止めてリストに入れた
2. 「番組の切り抜きはNG、店名・住所・放送日はOK」という線引きをそのまま機能の設計にした
3. テレビの店から「行きたい」に足し、行ったら自動で印がつく流れ
