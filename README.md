# 投稿卓

X / Instagram / TikTok / YouTube への投稿を1か所で管理し、**Instagram へは API で実際に投稿する**ローカルアプリ。
外部ライブラリは使っていないので `npm install` は要りません。

```
cp .env.example .env
node server.js
```

→ ブラウザで http://127.0.0.1:3000

自分のPCの中だけで動きます。ログインもデータベースもありません。投稿データは `data/posts.json`、画像・動画は `data/media/` に置かれ、どちらも Git の対象外です。

## できること

| | |
|---|---|
| 投稿の作成・編集・削除 | 本文、投稿先SNS、予定日時、画像・動画 |
| ステータス管理 | 下書き / 投稿予定 / 投稿済み / 失敗 |
| 投稿履歴 | 投稿ごとに、いつ何が起きたかを記録 |
| **Instagram へ実投稿** | 画像（フィード）とリール（動画）に対応 |
| 予約投稿 | 時刻が来たら自動で Instagram へ送信（アプリ起動中のみ） |
| X / TikTok / YouTube | 内容と状況の管理＋本文コピー（API連携は未対応） |

## サーバーが2つある理由

```
[ブラウザ] ── http://127.0.0.1:3000 ── [本体]      画面・操作・トークン
                                          │
                                     data/media/
                                          │
[Instagram] ── https://xxx.trycloudflare.com ── [メディア専用 :3001]   読むだけ
```

Instagram はメディアファイルを直接受け取らず、**こちらが渡した公開URLを見に来て取得します**。つまりローカルの画像を外から見える状態にする必要があります。

このとき本体サーバーごとトンネルに繋いでしまうと、URLを知った人が誰でも投稿を操作できてしまいます。そこで **`data/media/` を読み取り専用で配るだけのサーバーを別に立て、トンネルはそちらにだけ繋ぎます**。メディアサーバーは GET と HEAD しか受け付けず、`/media/` 以外のパスには何も返しません。

## Instagram 連携の手順

### 1. Instagram をプロアカウントにする

Instagram アプリ → 設定 → アカウントの種類とツール → **プロアカウントに切り替える**（クリエイターでOK）。
個人アカウントのままだと API が権限エラーで弾きます。いつでも個人に戻せます。

### 2. Meta でアプリを作る

1. [Meta for Developers](https://developers.facebook.com/) に登録
2. アプリを新規作成。ユースケースは **Instagram** を選ぶ
3. 左メニューの **Instagram → API setup with Instagram login** を開く
4. 手順1で自分の Instagram アカウントを接続する
5. 手順2の権限に `instagram_business_basic` と `instagram_business_content_publish` があるか確認
6. 手順3の **Generate token** でトークンを発行する

**自分のアカウントに投稿するだけなら、Meta の審査（App Review）は要りません。**
他の人のアカウントを繋ぐ段階になって初めて審査が必要になります。

### 3. アプリシークレットを .env に書く

Meta の アプリ設定 → ベーシック の **Instagram App Secret** を `.env` の `IG_APP_SECRET` に貼ります。
短期トークンを長期トークンに交換するときに使います。

### 4. トンネルを開く

別のターミナルで:

```
cloudflared tunnel --url http://localhost:3001
```

表示された `https://....trycloudflare.com` を、アプリの「連携設定」①に貼って保存します。
アカウント登録は要りません。ターミナルを閉じるとURLも消えます。**URLが変わるたびに貼り直してください。**

### 5. トークンを登録する

「連携設定」②に Generate token で出たトークンを貼って「登録して接続テスト」。
1時間で切れる短期トークンを、**60日もつ長期トークンへ自動で交換します**。ヘッダーに `@ユーザー名` が出れば接続成功です。

期限が近づいたら「期限を延長」を押すと、そこからまた60日になります。

## 投稿の条件

| | |
|---|---|
| リール | MP4（H.264 + AAC）／9:16 前後／3秒〜15分／1GB以下 |
| 画像 | JPEG 推奨／8MB以下／縦横比 4:5〜1.91:1 |
| キャプション | 2,200文字まで |
| 回数 | 24時間で100投稿まで |

条件から外れると Instagram 側の変換で失敗します。アプリはその理由を日本語に直して画面に出します。

## 秘密情報の扱い

- トークンとシークレットは `.env` にだけ置き、`.gitignore` で Git から外してあります
- `.env` は パーミッション 600（自分だけ読める）で書き込みます
- 画面に返すのは **先頭6文字だけ**（`IGAAxx…(195文字)`）。全体は一度もブラウザに送りません
- サーバーのログにもトークンは出しません
- 万一どこかに貼ってしまったら、Meta の管理画面でトークンを作り直せば古いものは無効になります

## テスト

```
node test/app.test.js
```

Instagram への通信部分だけ偽物に差し替えて、投稿の作成・保存・予約発火・エラー時の記録・メディアサーバーの締まり具合まで19項目を確認します。ネットワークには出ません。

## まだできないこと

- X / TikTok / YouTube への実投稿（X は無料枠が終了、TikTok は審査に2〜4週間、YouTube は未着手）
- 他の人のアカウントを繋ぐこと（Meta の審査が必要）
- PCを閉じている間の予約投稿（常時動くサーバーが必要）
- カルーセル（複数枚）投稿、ストーリーズ
