Instagram 連携

ここで入れた情報は .env に保存され、あなたのPCの外には出ません。画面にも先頭6文字しか表示しません。

別のターミナルで cloudflared tunnel --url http://localhost:3001 を実行し、表示された https URL を貼ってください。
Instagram はファイルを直接受け取らず、この公開URLを見に来て取得します。

貼ると、1時間で切れる短期トークンを60日もつ長期トークンへ自動で交換します（これが OAuth の実際の通信です）。

トークンの取り方（Meta の管理画面）
  1. Instagram アプリで アカウントをプロアカウント（クリエイター）に変更する
  2. Meta for Developers に登録し、アプリを新規作成（ユースケースは「Instagram」）
  3. アプリ内の Instagram → API setup with Instagram login を開く
  4. 手順1で自分の Instagram アカウントを接続する
  5. 手順2の権限に instagram_business_basic と instagram_business_content_publish があることを確認
  6. 手順3の Generate token でトークンを発行し、上の欄に貼る
  7. アプリ設定 → ベーシック の Instagram App Secret を .env の IG_APP_SECRET に書く
