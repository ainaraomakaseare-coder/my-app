# ごはんの足跡

食べたものを、写真・日付・お店（場所）・値段・評価で残すごはんの記録アプリ。旅の足跡の「記録」部分だけを取り出したような形で、旅行のような期間は持たず、毎日の記録が1本の一覧になる。HTML1枚＋JS（ビルド・サーバーなし）。

```
open index.html   # またはこのフォルダを静的に配信する
```

公開URL（GitHub Pages）：https://ainaraomakaseare-coder.github.io/my-app/apps/gohan-ashiato/

## できること

- 写真（最大10枚、長い辺1600pxに縮めて保存）・料理名・日付・時刻・朝/昼/夜/おやつ/飲み・お店や場所・値段・★1〜5・メモを記録
- 写真を選ぶと、撮影日時（と、残っていれば撮影場所）を自動で入れる。「現在地を記録」ボタンでも位置を残せる（iPhoneのブラウザは写真の位置情報を消すので、場所まで入るのはiPhoneアプリ版・Android・PC）
- 位置があると、近くの飲食店の候補（最大10件・近い順）を出し、タップでお店の名前に入れる。旅の足跡のWorkerの `GET /places/nearby?kind=food`（Google Places、使えなければOpenStreetMap）を使う。送るのは緯度・経度だけ
- お店・料理名は過去の入力から候補が出る
- 一覧：月ごとの見出し（件数・合計金額）、今月の件数・合計・平均評価、検索、★4以上・時間帯で絞り込み、新しい順/古い順/評価順/値段順、写真だけで並べる表示
- 「お店」タブ：お店ごとの回数・平均評価・合計・最後に行った日（タップでそのお店の記録だけを表示）
- 詳細：写真の拡大、Googleマップで開く、同じお店のほかの記録
- 設定：写真ごとJSONに書き出し（行きたい場所も含む）・読み込み（同じ記録は更新日時の新しいほうを残す）
- 「行きたい」タブ：行きたいお店・場所のリスト。一覧と地図を切り替えられる。お店の名前で探して足す（旅の足跡のWorkerの `/places/search` → `/places/details`）か、いまいる場所で足す。テレビで見た番組名・放送日・メモも残せる。「近い順」「まだ行ってない」「テレビで見た」で絞り込み
- 「テレビ」タブ：テレビで紹介されたお店（`tv-shops.json`）を番組をまたいで一覧・地図で見る。番組で絞り込み、近い順。詳細から「行きたいに足す」「行った記録をつける」（お店の名前と位置を入れた記録フォームが開き、保存すると詳細に戻る）
- 行ったかどうかは記録から自動で判定する（お店の名前がどちらかに含まれる。お店の名前が無い記録は40m以内）

iPhoneアプリ版は `apps/gohan-ashiato-ios`（同じコードを同梱）。

## テレビの店（tv-shops.json）

番組の映像・スクショ・ロゴは使わず、**店名・住所・放送日・出どころのリンク**だけを載せる。1件の形：

```json
{ "id": "senju-okachimachi", "name": "らぁめん千寿 御徒町店", "address": "東京都台東区上野4-2-5 美野里ビル1F",
  "station": "御徒町駅", "genre": "札幌味噌ラーメン", "lat": null, "lng": null,
  "links": [{ "label": "お店の公式サイト", "url": "https://..." }],
  "appearances": [{ "program": "番組名", "channel": "局", "aired": "2026-10-29", "title": "回のタイトル", "url": "https://（番組の公式情報）" }],
  "sources": ["確かめたページ"], "checkedAt": "2026-10-29" }
```

- 足すときは番組の公式情報・お店の公式情報で確かめ、`sources` に残す。グルメサイトやまとめブログを丸ごと写さない（規約・編集著作物の問題）
- `lat`/`lng` が無いお店は、アプリが住所（建物名を除く）を国土地理院の住所検索に送って位置を調べ、端末に覚える（`gohan-ashiato.geo.v1`）。分かっていれば入れておくと通信が要らない
- Googleのお店の情報（Places API の結果）はリストに保存しない（規約で長く保存してよいのは place_id だけ）
- 2026-10-29時点は581店（同じ店が複数の回に出たものは1件にまとめた）。番組ごと：ぶらり途中下車の旅（日本テレビ）223／町中華で飲ろうぜ（BS-TBS）196／吉田類の酒場放浪記（BS-TBS）100／おんな酒場放浪記（BS-TBS）61／かまいまち（フジテレビ）1。2024-11〜2026-10放送の回。位置は580店に入れた（国土地理院の住所検索）
- 新しい回を足すとき：`node scripts/collect-tv-shops.mjs [--dry-run]`。4番組の公式ページから、リストにある最新の放送日より新しい回だけを読んで足し（robots.txtに従い1秒に1回）、追加件数・確認待ち（ぶらりで飲食店か分からない店）・読めなかったページをMarkdownで出す。解析のテストは `node test/collect.test.js`
- 集めた元は番組の公式ページだけ（BS-TBSの各店ページ、日本テレビのぶらりの放送後記事）。テレビ東京（`anthropic-ai` を robots.txt で全面禁止）とNHK（同）は使っていない。じゅん散歩（テレビ朝日）は公式に過去回の店リストが無い

毎週月曜の朝（日本時間6時）に GitHub Actions（`.github/workflows/gohan-ashiato-tv-shops.yml`）が上のスクリプトを動かし、店が増えていればPRを作る。PRの本文に「確認待ち」（飲食店か自信のないもの）が並ぶので、要るものは手で足してからマージする（確認待ちは次の週には出てこない）。PRを作るには、リポジトリの Settings → Actions → General の「Allow GitHub Actions to create and approve pull requests」をオンにしておく。

## データの保存場所

記録は`localStorage`（`gohan-ashiato.records.v1`）、行きたい場所は`gohan-ashiato.wants.v1`、写真はIndexedDB（`gohan-ashiato-photos`）。この端末のブラウザの中だけに保存し、サーバーには送らない。iPhoneのSafariはしばらく開かないサイトのデータを消すことがあるため、ホーム画面に追加して使うこと・ときどき書き出すことを設定画面で案内している。

## 旅の足跡から流用したもの

見た目（薄いグレーの地・白いカード・影だけで区切る）、地図（`vendor/leaflet`、Leaflet 1.9.4・BSD-2、OpenStreetMapのタイル）と、写真のExif（撮影日時・GPS）を読む処理（`core.js`の`jpegExif`、元は`apps/day07-tabilog/app.js`）。

## テスト

```
node test/core.test.js            # 並べ替え・絞り込み・集計・入力チェック・書き出しファイル・Exif・行きたい場所・テレビの店・距離・行った判定
node test/ui.smoke.js [保存先]     # 実ブラウザで登録〜編集〜削除〜書き出し/読み込み・行きたい/テレビの一覧と地図（要 playwright）。保存先を渡すと画面のスクリーンショットも撮る
```

## 引き継ぎメモ（2026-10-28）

- 知人（日常の食べ物だけを記録したい人）のために、旅の足跡とは別アプリとして作った。旅の足跡にモードを足す案・コピーして削る案は採らなかった
- Web版は #194 で公開済み。iPhoneアプリ化と近くのお店の候補は次のPR
- 近くのお店の候補は旅の足跡のWorker（`apps/day07-tabilog/worker`）に `kind=food` を足したもの。Workerを `wrangler deploy` するまでは「お店の候補を読み込めませんでした」になる（記録自体はできる）。Googleの料金は旅の足跡と共通の枠（Nearby Search Pro、月5,000回まで無料）
