## 説明文（下書き）

```
旅行の思い出を、写真や動画とともに「日ごと・時間ごとのきろく」として残せるアプリです。

・いつ、どこで、何をしたかを時系列で記録
・費用の明細も1件ずつ記録し、自動で合計
・写真だけでなく動画も添付できる
・宿泊した場所は自動でひと目でわかる表示に
・家族や友人にリンクを送るだけで、一緒に見たり書き足したりできる
・別行動した時間も、同じ予定の中に記録を分けて残せる

旅行のあと、家族に「こんな旅だったよ」と見せられる記録を、ひとつずつ積み重ねていくアプリです。
```

## App Privacy（データ収集の申告）

App Store Connectの「App のプライバシー」画面で聞かれる内容の目安です（実際の画面の選択肢に沿って回答してください）。

| データの種類 | 収集する？ | 用途 | 本人の識別に使う？ |
|---|---|---|---|
| メールアドレス | する（ログイン時） | アプリの機能（ログイン） | する |
| 氏名 | する（ログイン時） | アプリの機能（「記録した人」への自動入力） | する |
| 写真・動画 | する（ユーザーが投稿） | アプリの機能 | する（旅行の記録に紐づく） |
| 位置情報 | しない | - | - |
| 連絡先 | しない | - | - |
| 閲覧履歴・広告用データ | しない | - | - |

「トラッキングに使用」は**いいえ**（広告目的の第三者への提供・突合は行っていません）。

## スクリーンショットについて

実機・シミュレータ、またはNode.js + Playwrightでの自動撮影で、実際の画面のスクリーンショットを用意してください（6.5インチ・6.7インチクラスの解像度が必須になることが多いです。要件は申請時の画面で確認してください）。マーケティング加工をする場合も、実際の画面内容を反映したものにしてください。
