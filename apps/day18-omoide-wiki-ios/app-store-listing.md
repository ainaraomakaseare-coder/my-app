# おもいでWiki：App Store 申請用の下書き

App Store Connect の入力画面で、ここからコピーして使ってください。画面の項目名は変わることがあるので、近い項目に当てはめてください。

## 自動入力（GitHub Actions）

GitHub の Actions →「おもいでWiki App Store 申請の下書きを入力」→ Run workflow（mode：apply）で、次の内容を App Store Connect に入力できます。「審査へ提出」は押しません。

- 入力できるもの：バージョン（1.0.0）、名前・サブタイトル・プライバシーポリシーURL、カテゴリ、年齢制限（すべて「なし」）、説明文・キーワード・プロモーション用テキスト・サポートURL、審査メモ、申請に使うビルド、スクリーンショット5枚
- 入力する中身：`store-metadata.json`（文章を直すときはここと、このファイルの両方を直す）
- 何度実行しても同じ結果になります。スクリーンショットは、すでに別の画像が入っていたら上書きしません
- mode を check にすると、いまの状態を読むだけで何も書き換えません
- APIで入力できないもの（手で入力）：Appのプライバシー、価格と配信地域、審査の連絡先、著作権

## 申請の前に済ませること

- [ ] **ビルド(9)以降を使う**：AIへの送信の同意画面（ガイドライン 5.1.2）と、iPhone専用の設定が入ったのは(9)から。(8)以前で申請すると、同意なしで外部のAIに送っているとして却下される可能性が高い。iPad用スクリーンショットも求められる
- [ ] **プライバシーポリシーのページが開けることを確認**（下記URL。mainにマージされるとGitHub Pagesに出る）
- [ ] **Worker（omoide-wiki-ai）が動いていることを確認**：審査中にAIが止まっていると「機能しない」と判断されやすい。Gemini・OpenAI とも有料枠で残高があること
- [ ] スクリーンショット5枚をアップロード（`store-screenshots/omoide-wiki-1〜5.png`）

## 説明文

```
おもいでWikiは、ひとりの人生を、質問に答えるだけで「百科事典のような1ページ」にまとめていくアプリです。

生まれた場所、子どものころの遊び、はじめての仕事、結婚、家族、大切にしている言葉――。アプリが順番に質問するので、答えていくだけで、目次・年譜・プロフィール表のついた、その人だけのページができあがります。

■ 声で答えるだけ
質問を読み上げるので、聞いて、話して答えるだけ。話し終わりに「次」と言えば、ボタンを押さずに次の質問へ進みます。文字を打つのが苦手な方にも。

■ AIがもう一歩深く聞き返す
「38年も先生を続けたなんて、すごいですね！一番心に残っている教え子は？」――回答に合わせて、AIが次の質問を考えます。学校の名前や年、そのときの気持ちまで、本物の人物記事のように聞き出します。

■ 少しずつ、何日かに分けて
1回に聞く数は3問・5問・10問から選べます。答えた質問は二度と聞かないので、疲れたらそこで終わり、続きはまた今度。あとから回答を書き直すこともできます。

■ みんなで持ち寄る
家族それぞれが覚えているエピソードや写真を持ち寄れます。家族旅行の「過ごした一日」も、別行動した時間ごとに記録できます。

■ ファイルで送る
できあがったページをファイルにして、家族に送れます。受け取った人は、そのままページを見ることも、自分の端末で続きを書くこともできます。

■ データは端末の中だけ
アカウント登録はいりません。記録は端末の中だけに保存されます。AIの機能を使うときは、送る内容を確認して同意してから使います（使わない場合も、決まった質問と端末の声でインタビューできます）。

敬老の日や誕生日に、親やおじいちゃん・おばあちゃんと一緒に。聞いておけばよかった、となる前に。
```

## 年齢制限（年齢区分の質問への答え方）

すべての質問に「なし」「いいえ」で答える想定です。結果は **4+** になる見込みです。

- 暴力・性的な内容・ギャンブル・薬物など：**なし**
- ユーザー生成コンテンツ（他人が投稿した内容が表示される）：**いいえ**（不特定多数に公開される場はない。ファイルで送るのは利用者が選んだ相手だけ）
- メッセージ・チャット機能：**いいえ**
- 制限のないWebアクセス：**いいえ**
- 広告：**いいえ**
- 医療・健康の情報：**いいえ**（「病気・けが」の質問はあるが、思い出として聞くだけ）

## App のプライバシー（データ収集の申告）

**迷ったら「多めに申告」が安全です。** AIの機能では文章がOpenAI・Googleに送られ、各社で不正利用の監視のため一定期間保存されることがあるため、下記のように申告するのをおすすめします。

**「データを収集していますか？」→ はい**

| データの種類 | 収集する？ | 用途 | ユーザーに紐づく？ | トラッキング |
|---|---|---|---|---|
| ユーザーコンテンツ → その他のユーザーコンテンツ（回答・エピソードの文章） | する | アプリの機能 | いいえ | いいえ |
| 氏名 | しない（ページの呼び名は文章の一部として上の項目に含まれる） | - | - | - |
| 写真・ビデオ | しない（端末の中だけ。外部に送らない） | - | - | - |
| 音声データ | しない（文字起こしはiOSの機能。録音を本アプリが送ることはない） | - | - | - |
| 連絡先・位置情報・識別子・使用状況データ・診断 | しない | - | - | - |

「トラッキングに使用」は**いいえ**（広告なし・他社データとの突合なし）。

## 輸出コンプライアンス（暗号化）
