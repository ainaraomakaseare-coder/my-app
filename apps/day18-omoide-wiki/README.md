# おもいでWiki

ひとりの人生も、サークルやチームの思い出も。質問に答えたり、みんながエピソードを持ち寄ったりしながら、その人・その場所の「Wikipedia」を育てていくアプリです。HTML・CSS・JSだけで動き、ビルドもサーバーも要りません。

```
open index.html
```

すべてこの端末のブラウザの中（localStorage）に保存されます。リロードしても続きから使えます。

## できること

- **質問で深掘りする**：人物像・好きなもの・特技・エピソードを、カテゴリごとの質問に沿って少しずつ聞き出します。文字入力でも、マイクに向かって話しても答えられます（対応ブラウザのみ）。「音声で会話する」をオンにすると、質問を読み上げてから自動でマイクが立ち上がります。
- **エピソードをみんなで持ち寄る**：写真つきの思い出を1本ずつ追加できます。誰が書いたか・いつ頃の話かも記録されるので、あとから見返したときに「誰が教えてくれた話か」が分かります。
- **完成ページ**：集まった記録をWikipedia風の1ページにまとめます。プロフィール表・概要・人物像・好きなもの・特技・エピソードのアルバムと年表・寄稿者一覧。印刷ボタンでそのままPDF化や紙での掲示もできます。
- **サーバーなしで複数人ぶんを合体する**：一人がこのアプリで下書きを作り、書き出したJSONファイルを他の人に配る→それぞれが自分の端末でエピソードを書き足して書き出す→最後に全部のJSONを「読み込んで合体する」に渡すと、同じWikiとして1つにまとまります（同じ記録が重複しないよう、内容ごとにID管理しています）。

## 使い方の流れ（複数人で作る場合）

1. 誰か一人が「＋ 新しく作る」でWikiを作り、書き出したJSONを他のメンバーに配る
2. 配られたJSONを各自が「JSONを読み込んで合体する」で自分の端末に取り込む
3. 各自がインタビューやエピソード追加で書き足し、また書き出す
4. まとめ役が全員ぶんのJSONを一度に読み込んで合体する（重複した記録は自動でまとめられます）

## 写真について

写真は選んだ時点で自動的に縮小・圧縮してから保存します（長辺1280px・JPEG品質72%程度）。外部のサーバーには一切送信されません。ただし端末のブラウザ保存には上限があるため、写真をたくさん貼るWikiは定期的にJSONへ書き出してバックアップすることをおすすめします。

## 音声について

音声入力・読み上げはブラウザ標準のWeb Speech APIを使っています。Chrome・Edge（PC/Android）での動作を確認しています。対応していないブラウザでは自動的にマイクボタンが使えない旨を表示し、文字入力だけで問題なく使えます。音声認識の処理はブラウザの実装に依存し、外部にAPI利用料は発生しません。
