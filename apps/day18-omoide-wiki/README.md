# おもいでWiki

ひとりの人生も、サークルやチームの思い出も。質問に答えたり、みんながエピソードを持ち寄ったりしながら、その人・その場所の「Wikipedia」を育てていくアプリです。HTML・CSS・JSだけで動き、ビルドもサーバーも要りません。

```
open index.html
```

すべてこの端末のブラウザの中（localStorage）に保存されます。リロードしても続きから使えます。

## できること

- **質問で深掘りする**：生い立ち・経歴（生まれ→幼稚園→小学校→中学校→高校→大学・就職→転機、というように年代順に。高校やサークル・アルバイト先の友人関係も聞きます）・人物像・好きなもの・特技・エピソードを、カテゴリごとの質問に沿って少しずつ聞き出します。質問は「性格は？」のような抽象的な聞き方ではなく、**「その性格が一番はっきり出た、具体的な出来事を一つ教えてください」のように、実際にあった場面を聞く言い回し**にしています（実在のWikipedia記事の「来歴」が、具体的な出来事の積み重ねでできているのに合わせています）。また、**答える側がウキウキ・ワクワクしながら話したくなるような、明るく前向きな言い回し**を意識しています。趣味・特技を聞く質問も強化しました。文字入力でも、マイクに向かって話しても答えられます（対応ブラウザのみ）。「音声で会話する」をオンにすると、質問を読み上げてから自動でマイクが立ち上がります。**初回はONの状態で始まり、オン・オフの選択は端末に記憶されるので、次回インタビューを開いたときも毎回オンにし直す必要はありません。** 話し終わりに「次」と言うと、ボタンを押さなくても次の質問に進みます（お年寄りなど、操作が難しい人でも声だけで進められます）。**一度答えた質問は、インタビューを開き直しても繰り返し聞かれません。** 「この質問はとばす」を押した質問も、答えていなくても二度と出てきません（もう聞かれたくない質問を確実に消せます）。**「前の質問に戻る」を押すと、直前の回答をいったん取り消して書き直せます**（言い間違えた・もっと話したい、というときのために）。生い立ちのカテゴリには、結婚・引っ越し・退職など**人生の節目の質問**も含まれていて、50年後に読み返したときにも「こういう人生を歩んできたんだ」と分かる記録を目指しています。**どの質問に対しても、任意で写真を添えられます**（エピソードと同じ、選んだ時点で自動圧縮する仕組みをそのまま使っています）。また、**15問答えるごとに「少し休憩しますか？」と確認します**。ここで「今日はここまでにする」を選んでも、それまでの回答はすべて保存済みなので、続きはまた別の日に始められます（長く話すと疲れる相手にインタビューするときのために）。
- **AIがその場で深掘りする、育てるモード（DAY19・要Worker公開）**：「AIで深掘りする」をオンにすると、回答した内容を読んでAIがその場で追加の質問を1つ作って返します（例：「留学した」→「留学のとき、何を思っていましたか？」）。AIは**「その人の人生をもっともっと深く知っていきたい、プロのインタビュアー」**という立ち位置で、**答える側がウキウキした気持ちで話したくなるような、明るく前のめりな聞き方**をします。ただの質問文ではなく、**「それは大変でしたね」のような短い相づちを添えてから聞く**、雑談のような自然な話し言葉にしています。**深掘りを続けるかどうかは、直前の回答の分量・具体性で判断します**（一言だけの薄い回答なら無理に掘らず、エピソードが豊富な回答ならどんどん深掘りします）。趣味・特技の話が出たときも積極的に深掘りする観点を追加しました。1つの話題につき最大6往復まで。**決まっている質問を全部聞き終えたら、そこで終わらずに、プロのインタビュアーとしてこれまでの内容全体を踏まえて新しい質問を考え続けます**（年代や時期を絞って深く聞くこともあります）。記録が増えてくると、AIが同じような質問を再び作ってしまうことがあったため、**そのカテゴリで既に聞いた質問の一覧をAIに渡し、同じ質問を繰り返さないよう指示しています**（そこから自然に派生する新しい角度の質問は歓迎します）。音声モードと組み合わせると、質問の読み上げ→話して答える→AIの追い質問の読み上げ→また話す、という会話がそのまま続きます。少額のAPI利用料が発生するため、Workerを公開するまでは無効化されたままです（`worker/README.md` 参照）。
- **エピソードをみんなで持ち寄る**：写真つきの思い出を1本ずつ追加できます。誰が書いたか・いつ頃の話かも記録されるので、あとから見返したときに「誰が教えてくれた話か」が分かります。任意で「旅行・イベント名」と「その場にいた人」を付けられます。旅行・イベント名は入力すると既存の候補が出るので、表記ゆれ（「沖縄旅行」と「沖縄旅行2023」など）で同じ旅行が別々にまとまってしまうのを防げます。データ上も、旅行・イベントは各エピソードが属する1つの記録（Trip）として持っていて、「旅行・イベントでまとめる」の詳細画面にある「✏️ 名前を変更」で直せば、紐づく全エピソードに反映されます。
- **旅行・イベントでまとめる（DAY19）**：ダッシュボードの「旅行・イベントでまとめる」から、「旅行・イベント名」をつけたエピソードだけを、旅行・イベント単位で見返せます。一覧では旅行名ごとに写真・参加者（書いた人＋その場にいた人）・エピソード件数が並び、選ぶと「だれがいて」「どんな出来事があったか」を写真つきで時系列に見られます。人物・サークルの「Wikipedia」とは別に、みんなの思い出日記のような使い方をしたいという要望から追加しました。完成ページのアルバムも引き続き旅行名ごとにまとまります。
- **完成ページ**：集まった記録を、実際のWikipediaの配色・書体・構成（目次box・infobox・カテゴリ欄）に寄せた1ページにまとめます。プロフィール表・概要・人物像・好きなもの・特技・エピソードのアルバムと年表・寄稿者一覧。印刷ボタンでそのままPDF化や紙での掲示もできます。
- **AIでまとめる（DAY19・要Worker公開）**：完成ページの「✨ AIでまとめる」を押すと、一問一答の生の回答を、実際のWikipedia記事のような自然な文章に書き直します（事実を創作せず、三人称のWikipedia文体に整えるだけ）。まとめた後も「元の回答を見る」でいつでも元のやり取りを確認できます。記録が無い項目や、まとめてもうまくいかなかった項目は、これまでどおり一問一答のまま表示されます。
- **サーバーなしで複数人ぶんを合体する**：一人がこのアプリで下書きを作り、書き出したJSONファイルを他の人に配る→それぞれが自分の端末でエピソードを書き足して書き出す→最後に全部のJSONを「読み込んで合体する」に渡すと、同じWikiとして1つにまとまります（同じ記録が重複しないよう、内容ごとにID管理しています）。

## 使い方の流れ（複数人で作る場合）

1. 誰か一人が「＋ 新しく作る」でWikiを作り、書き出したJSONを他のメンバーに配る
2. 配られたJSONを各自が「JSONを読み込んで合体する」で自分の端末に取り込む
3. 各自がインタビューやエピソード追加で書き足し、また書き出す
4. まとめ役が全員ぶんのJSONを一度に読み込んで合体する（重複した記録は自動でまとめられます）

## 写真について

写真は選んだ時点で自動的に縮小・圧縮してから保存します（長辺1280px・JPEG品質72%程度）。外部のサーバーには一切送信されません。ただし端末のブラウザ保存には上限があるため、写真をたくさん貼るWikiは定期的にJSONへ書き出してバックアップすることをおすすめします。

## 音声について

音声入力・読み上げはブラウザ標準のWeb Speech APIを使っています。Chrome・Edge（PC/Android）での動作を確認しています。対応していないブラウザでは自動的にマイクボタンが使えない旨を表示し、文字入力だけで問題なく使えます。音声認識の処理はブラウザの実装に依存し、外部にAPI利用料は発生しません。

## AI深掘りについて（DAY19）

固定の質問リストだけでは「そのとき何を思っていたか」のような話を引き出しきれないため、回答内容に応じてAIが追加の質問を1つ作る機能を追加しました。DAY05のドラマ王と同じ、Cloudflare Worker経由でOpenAI APIキーを秘匿する構成です（`worker/` フォルダ、詳細は `worker/README.md`）。

- Worker未公開の状態では「AIで深掘りする」トグル自体が表示されず、通常の固定質問インタビューだけで使えます
- Workerを公開すると、「AIで深掘りする」は**初回からONの状態**で始まります（費用よりも深掘りの質を優先したいという要望のため）。オフにすると次回からも記憶されます
- 個人的な回答を扱うため、DAY05と違い**キャッシュはしません**（レート制限のみ）
- 「日時・場所」「一緒にいた人」「そのときの気持ち」「きっかけ」「印象的な言葉」「その後の変化」など、あらかじめ決めた「深掘りの観点」の中から、AIが今の回答にとって一番ネタになりそうなものを選んで質問を作ります（完全に自由な深掘りにすると話が散らかるため）
- 1つの話題につき深掘りは最大6往復まで。AIが「十分掘れた」と判断すればそれより早く打ち切ります
- プロフィール表に生年月日・結成年などが書かれていれば、その時代に日本で流行っていた具体的なテレビ番組・音楽・芸能人などを挙げて「〇〇はお好きでしたか？」のように尋ねることがあります（年代が分からない場合は無理に使いません）
- 費用の目安・抑え方は `worker/README.md` を参照してください
