- LPのURLを貼ると、`lp/img/og.png` の画像（「おじいちゃんの人生にも、1ページを。」）がカードとして出ます

## X（旧Twitter）

### 案1：コンセプト一本で（いちばんおすすめ）

```
Wikipediaがあるのは、有名人だけ。

でも、おじいちゃんの人生にも、お父さんの若いころにも、残しておきたい話がある。

AIのインタビュアーに聞かれるまま答えるだけで、その人の人生が百科事典みたいな1ページになるアプリを作りました。

「おもいでWiki」無料です👇
https://ainaraomakaseare-coder.github.io/my-app/apps/day18-omoide-wiki/lp/
```

### 案2：「聞いておけばよかった」から

```
父が昔どんな仕事をしてたのか、ちゃんと聞いたことがない。
祖父が若いころ何に夢中だったのかも知らない。

そういう「改まって聞く」を、AIが代わりにやってくれるアプリ「おもいでWiki」を作りました。

質問を読み上げてくれるので、声で答えるだけ。
答えが百科事典風のページにまとまります。

https://ainaraomakaseare-coder.github.io/my-app/apps/day18-omoide-wiki/lp/
```

### 案3：使い方を見せる（画像4枚と一緒に）

```
「おもいでWiki」でできること

① AIが質問を読み上げる → 声で答えるだけ
② 答えにあいづちを打って、もう一歩深く聞き返してくる
③ 集まった答えが、目次・年譜つきの百科事典風ページに
④ ファイルで家族に送れば、アプリがなくても読める

記録は端末の中だけ。住所や電話番号は聞きません。
無料・登録なし。

https://ainaraomakaseare-coder.github.io/my-app/apps/day18-omoide-wiki/lp/
```

### 案4：開発の裏話（「30日で30アプリ」企画として）

```

年や学校名ばかり聞くと話す気がしぼむので、「そのとき一番びっくりしたことは？」みたいな、話したくなる質問を優先させています。

### スレッドにするなら（案1のあとに続ける）

```
2/ 使い方は、AIの質問に答えていくだけ。
質問を読み上げてくれるので、スマホが苦手な親や祖父母でも、声で答えられます。
「次」と言えば次の質問へ。
```

```
3/ AIは答えを聞いて「りんごの寒天、やさしい味が目に浮かびます」みたいにあいづちを打って、もう一歩深く聞いてきます。
1回5問ずつなので、疲れたらそこで終わり。続きはまた今度。
```

```
4/ 答えは端末の中だけに保存されて、作った私にも見えません。
住所や電話番号みたいな、聞かれると構えてしまうことは聞かない作りにしました。
```

```
5/ 敬老の日や帰省のときに、ぜひ。
「聞いておけばよかった」に、なる前に。
https://ainaraomakaseare-coder.github.io/my-app/apps/day18-omoide-wiki/lp/
