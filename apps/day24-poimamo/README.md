# ポイまも

楽天ポイント・Vポイント・ANAマイレージ・Amazonポイントなど、あちこちに散らばったポイントの残高と失効日を一箇所で見張るアプリ。HTML1枚で動き、ビルドもサーバーも要りません。

```
open index.html
```

## できること

- サービスごとに、ポイントの種類（期間限定／通常）・残高・失効日・メモを登録
- 失効日が近い順に自動で並び替え。失効間近（7日以内・30日以内）や失効済みは色分けして目立たせる
- 登録件数・合計ポイント・30日以内に失効する件数をひとめで確認できるサマリー表示
- ポイント画面のスクリーンショットをアップロードすると、AIが残高・失効日・ポイントの種類を読み取ってフォームに自動入力（**必ず内容を確認してから保存**する設計）
- データはこの端末のブラウザ内（localStorage）にのみ保存。JSONファイルへの書き出し・読み込みができ、機種変更のときも安心

## スクショの自動読み取りについて

各サービス（楽天ポイント、Vポイント、ANAマイレージ、Amazonポイントなど）へ**ID・パスワードで自動ログインして直接取得する機能は、あえて作っていません**。利用規約違反やセキュリティ上のリスクが大きく、サイトの仕様変更で頻繁に壊れる実装になるためです。

その代わり、ポイント画面のスクリーンショットをAI（画像理解）に読み取らせて自動入力する機能を用意しています。この機能を使うには`worker/`のCloudflare Workerを別途デプロイする必要があります（手順は`worker/README.md`参照）。**Workerを未設定のままでも、手入力での登録・管理はすべて問題なく使えます。**
