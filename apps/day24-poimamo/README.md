# ポイまも

楽天ポイント・Vポイント・ANAマイレージ・Amazonポイントなど、あちこちに散らばったポイントの残高と失効日を一箇所で見張るアプリ。HTML1枚で動き、ビルドもサーバーも要りません。

```
open index.html
```

## できること

- サービスを一覧でチケット風のカードとして表示。失効日が近い順に自動で並び替え、失効間近（7日以内・30日以内）や失効済みは色分けして目立たせる
- 1つのサービスが複数の内訳（例：楽天ポイントの「8/30失効の期間限定100pt」「9/30失効の期間限定10pt」「失効しない通常1000pt」）を同時に持てる。サービスをタップすると内訳の一覧・合計残高を確認できる詳細画面に遷移
- 登録サービス数・合計ポイント・30日以内に失効する内訳件数をひとめで確認できるサマリー表示
- 詳細画面から内訳を手入力で追加・編集・削除
- 「スクショから登録」（新しいサービスを追加）・詳細画面の「スクショで情報を更新する」（既存サービスの内訳を丸ごと更新）のどちらも、スクリーンショットを**複数枚まとめて選んでAIに読み取らせられる**。1画面に収まらない長い内訳一覧も、スクロールしながら複数枚撮れば漏れなく取り込める（**読み取り結果は編集可能な一覧として表示し、必ず内容を確認してから確定**。手入力だけで一覧を組み立てることもできる）
- 内訳ごとに「カレンダーに追加」ボタンから`.ics`ファイルをダウンロードでき、Google/Appleカレンダーなどにリマインダー（失効3日前に通知）として登録できる
- データはこの端末のブラウザ内（localStorage）にのみ保存。JSONファイルへの書き出し・読み込みができ、機種変更のときも安心

## スクショの自動読み取りについて

各サービス（楽天ポイント、Vポイント、ANAマイレージ、Amazonポイントなど）へ**ID・パスワードで自動ログインして直接取得する機能は、あえて作っていません**。利用規約違反やセキュリティ上のリスクが大きく、サイトの仕様変更で頻繁に壊れる実装になるためです。

その代わり、ポイント画面のスクリーンショットをAI（画像理解）に読み取らせて自動入力する機能を用意しています。この機能は`worker/`のCloudflare Workerとして公開済みです（詳細は`worker/README.md`参照）。**Workerが読み取れない・止まっている場合でも、手入力での登録・管理はすべて問題なく使えます。**

## テスト

```
node test/logic.test.js   # 失効判定・グルーピング・入力チェック・AI複数内訳の取り込み・カレンダー登録(.ics)ロジック
node test/ui.smoke.js     # 実ブラウザでの登録・詳細画面遷移・内訳の編集削除・複数枚スクショの一括読み取り・カレンダー登録・書き出し/読み込みの流れ（要 playwright）
```

## 月別の失効ポイントの読み取り

「失効予定」の下にある「7月 100ポイント」「8月 200ポイント」は別々の内訳として読み取ります。年が見出しなどから分かれば月末日を仮入力し、その旨を確認画面に表示します。年が分からない場合も月とポイント数を残し、失効日を補ってから保存します。獲得月・通算獲得数は失効内訳に含めません。

月末の補完はアプリ側で行いますが、画像からの文字・見出しの判別はAIによるため、保存前に確認してください。

Worker境界のテスト: `node test/worker.test.js`（外部API通信なし）。UIテストは `playwright` をインストールするか、`NODE_PATH` / `PLAYWRIGHT_MODULE` で指定してください。インストール済みEdgeを使う場合は `PLAYWRIGHT_CHANNEL=msedge` を設定します。

## 合計の二重計上防止

AIは合計（totalBalance）、明記された通常（regularBalance）、期間限定小計（limitedBalance）、期限別内訳（lots）を分けて読み取ります。合計1000pt・期間限定200ptなら通常800ptとしてコード側で計算します。通常が明記されていればその数値を使い、さらに期間限定を引くことはありません。合計と内訳の矛盾、小計と月別行の不一致、通常を計算するための内訳不足は422（inconsistent_balances）で返し、画像の追加や手入力を案内します。

既に保存したデータは自動変更しません。重複登録があるサービスの詳細画面から「スクショで情報を更新する」で読み取り直し、確認して更新してください。

## マイルと失効カレンダー

- 残高は `pt` と `マイル` を区別して保存・集計します。以前登録したANAマイレージもマイル表示になります。手入力・スクショ確認画面の「単位」で修正できます。
- 月間カレンダーに今日を強調し、失効日のセルに件数を表示します。日付を選ぶと、サービス名・残高・単位を確認でき、内訳からサービス詳細を開けます。前月・翌月・「今日へ」で移動できます。
- 通常ポイントや通常マイルにも期限を設定できます。期限がない、または未確認の残高はカレンダーに含めず、件数を案内します。端末のローカル日付を今日として使います。
- スクショは**同じサービスの画面を最大6枚**まとめて選びます。ANAの通常マイルの期限別一覧などは、通常の合計と二重加算せず各期限を保持します。
- 付与予定のカレンダーは失効予定ではありません。付与予定・判定中・通算獲得・累計・円相当・運用中を現在使える残高に加算しません。「最短期限」だけの小計は、全額がその日に失効するとは判断せず詳細画面の追加を求めます。

テストは画像認識後の構造化データと画面操作を検証しています。実際のAIによる画像認識は保存前に確認してください。
