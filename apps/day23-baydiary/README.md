# ベイ日記

横浜DeNAベイスターズの観戦記録をつける個人用日記アプリ。HTML1枚で動き、ビルドもサーバーも要りません。

```
open index.html
```

## できること

- 球場に行った日ごとに、対戦相手・スコア・勝敗・球場を記録
- 同行者、チケット代、天気・気温、写真を添えて記録
- 自分なりのMVP選手や、興奮したこと・印象に残ったシーンをメモ
- 年度ごとの観戦成績（勝敗・勝率）を自動集計
- 観戦した試合でよく名前を挙げた選手を「選手分析」画面でランキング表示（MVP=2pt、その他の活躍=1ptで集計）
- データはすべてこの端末のブラウザ内（localStorage・IndexedDB）に保存。設定画面から丸ごとJSONで書き出し・読み込みができ、機種変更のときも安心

## 試合結果の自動取得について

対戦相手やスコアを手入力する代わりに、設定画面で [api-sports.io](https://api-sports.io/) の無料APIキーを登録すると「試合結果をAPIから取得」ボタンで自動入力を試せます。ただしNPBの公式データを網羅した安定・無料のAPIは今のところ見当たらず、この機能は**試験的なベストエフォート**です。

実際にAPI-BASEBALLの無料プランで検証したところ、**2022〜2024年シーズンのデータにしかアクセスできず、2025年以降（今シーズン）の試合は取得できない**という制限があることが分かりました（`Free plans do not have access to this season, try from 2022 to 2024.`というエラーが返る）。そのため今シーズンの観戦記録では自動取得は使えず、手入力が基本になります。2022〜2024年の試合を後から記録する場合は自動取得を試す価値があります。取得できない日は素直に手入力してください（キーを登録しなくてもアプリの他の機能はすべて使えます）。
