# 人狼

参加者がそれぞれ自分のスマホで、**自分の役職だけ**を見られる人狼アプリ。1台のスマホを回して確認するやり方をやめるために作りました。

## 使い方

1. 親機（進行役の端末）でこのページを開き、参加者の名前と役職の構成を入れる
2. 「役職を配る」を押すと、1人ずつQRコードが出る
3. その人のスマホのカメラでQRを読むと、その人の端末に自分の役職だけが表示される
4. 全員に配り終えたら、親機の画面に沿って夜→朝→議論→投票と進める

占い師・霊媒師の結果も、その人の端末にQRで渡します。

## 仕組み

サーバーを使いません。役職は URL の `#` より後ろに入れてQRにしています。`#` より後ろはサーバーに送られないので、どこかに記録が残ることもありません。ゲームの進行状況は親機のブラウザ（localStorage）に保存され、途中でリロードしても続きから再開できます。

QRコードの生成は外部ライブラリを使わず `qr.js` に自前で実装しています。

## 気をつけていること

役職はURLに入っているだけで、暗号化はしていません。**本人以外にリンクを見せない**前提の作りです。人の端末を覗く人がいない、友達同士で遊ぶ場面を想定しています。

襲撃先・護衛先・投票は親機に入力するので、進行役にはその選択が見えます。

## テスト

```
node test/qr.test.js      # 自前のQR生成を本物のデコーダーで読み返す（要 jsqr）
```
