# 人狼

参加者がそれぞれ自分のスマホで、**自分の役職だけ**を見られる人狼アプリ。1台のスマホを回して確認するやり方をやめるために作りました。

## 使い方

1. 親機（進行役の端末）でこのページを開き、参加者の名前と役職の構成を入れる
2. 「役職を配る」を押すと部屋ができ、**全員共通のQR（リンク）**と、**1人ずつの4桁の番号**が出る
3. 全員に同じQRを読んでもらう（順番待ちは要りません。リンクをLINEで送っても構いません）
4. 進行役が、それぞれの人に自分の番号を伝える
5. 各自が自分の番号を入れると、その端末に自分の役職だけが表示される
6. 親機の画面に沿って夜→朝→議論→投票と進める

占い師・霊媒師の結果も、その人の端末にQRで渡します。

### 配り方は2通りあります

| 方式 | 向いている場面 |
|---|---|
| **まとめて配る**（共通QR＋4桁の番号） | 全員がその場にいるとき。順番待ちが要らない |
| **1人ずつ配る**（個別QR／個別リンク） | 番号を伝えるのが面倒なとき。離れている人にLINEで送りたいとき |

画面下のボタンでいつでも切り替えられます。

番号を入れると、まず**名前だけ**が出ます。ここで自分の名前かどうか確認してから役職を開く作りなので、番号を聞き間違えても気づけます。ちがう名前が出たら「ちがう人の名前が出ている」で入れ直せます。

## 仕組み

サーバーを使いません。役職は URL の `#` より後ろに入れています。`#` より後ろはサーバーに送られないので、どこかに記録が残ることもありません。ゲームの進行状況は親機のブラウザ（localStorage）に保存され、途中でリロードしても続きから再開できます。

部屋のリンクには全員ぶんの役職が入っていますが、**それぞれ自分の4桁の番号でしか開けない**ようにしてあります。番号から作った鍵で1人ぶんずつ包んであり、番号が合わないものは開きません。15万通りの番号を試して、他人の役職が誤って開くケースが0件であることを確認しています。

QRコードの生成は外部ライブラリを使わず `qr.js` に自前で実装しています。

## 気をつけていること

**友達同士で遊ぶ前提の作りです。強い暗号ではありません。**

- 4桁の番号は口頭で伝える運用なので、まわりに聞こえます。聞いた番号を自分の端末に入れれば、その人の役職は見られます
- 部屋のリンクを持っていれば、番号を総当たりすることも理屈のうえでは可能です（1万通り）
- 襲撃先・護衛先・投票は親機に入力するので、進行役にはその選択が見えます

本気で他人の役職を見ようとする人がいる場面には向きません。そこまでの秘密が要る場合は、サーバーを使って各自を認証する作りが必要です。
