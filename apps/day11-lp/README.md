# ドラマ検定 LP

DAY5・DAY10 で作った[ドラマ検定](../day05-dramaou/)に、遊んでもらうための入口を作りました。1枚のHTMLで動き、ビルドもサーバーも要りません。

```
open apps/day11-lp/index.html
```

## 誰に向けて、何をしてほしいか

ヒアリングで先に決めたことです。ここが決まっていないとコピーが書けません。

| | |
|---|---|
| 誰に | ドラマ好きの一般の人。開発者向けではない |
| 何をしてほしいか | 「今すぐ挑戦する」を押してアプリを開く |
| どこから来る | SNS や動画の概要欄 |

**売るためのLPではありません。** アプリは無料なので、価格表もプランもありません。やることは「押したくなるところまで連れていく」ことだけです。

## 構成と、その順番の理由

1. **ヒーロー** — 見出しと、実際の出題画面。何のサイトか3秒で分かるようにする
2. **作品の帯** — 知っている題名が並んでいれば、自分ごとになる
3. **あるある** — 「好きだった」と「覚えている」は別もの、と刺す
4. **3ステップ** — やることが少ないと分かれば、踏み出しやすい
5. **称号** — このアプリのいちばんの引き。どこまで行けるか気になる形にする
6. **作品と数字** — 17作品340問。載っていない作品も遊べることを明記する
7. **問題の質** — 雑なクイズではないことの説明。ここで信用を足す
8. **最後のCTA** — 読み切った人がすぐ押せる場所

**CTAは3か所**（ヒーロー／最後／脚注）。長いページの途中で気が変わった人を取りこぼさないためです。

## 載せている数字の出どころ

すべてアプリのコードから取りました。手で書き写していません。

| 数字 | 出どころ |
|---|---|
| 17作品 | `apps/day05-dramaou/index.html` の `BAKED` のキー数 |
| 340問 | 同じく `BAKED` の設問数の合計（17作品 × 20問） |
| 10問 | `TOTAL` |
| 称号6段階 | `RANKS` |

**アプリを変えたら、この数字も直してください。** 自動で追従はしません。

## 見た目について

アプリと地続きに見えるよう、同じ紫と白いカードで組んでいます。ただし**アプリ側にあるチャンネル一覧やダイレクトメッセージ風の造作は持ち込んでいません**。アプリの中の演出としては成立しますが、宣伝ページで同じことをすると別のサービスの公式ページに見えてしまうためです。
