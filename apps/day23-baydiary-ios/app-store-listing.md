## 説明文（下書き）

```
球場に足を運んだ日を、自分だけの観戦日記として残すアプリです。

・試合日、対戦相手、スコア、勝敗、球場を記録
・同行者、チケット代、天気・気温、写真も一緒に残せる
・自分なりのMVPや、興奮したシーン・印象に残ったプレーをメモ
・年度ごとの観戦成績（勝敗・勝率）を自動集計
・観戦した試合でよく名前を挙げた選手を、自動でランキング表示

サーバーを一切使わず、記録はすべてこの端末の中だけに残ります。書き出し機能でファイルに保存すれば、機種変更のときも安心です。

今シーズンの応援の記録を、試合ごとに積み重ねていくアプリです。
```

## App Privacy（データ収集の申告）

App Store Connectの「App のプライバシー」画面で聞かれる内容の目安です（実際の画面の選択肢に沿って回答してください）。

本アプリはサーバーを持たず、記録はすべて端末内（localStorage・IndexedDB）にのみ保存されます。開発者が利用者のデータを収集することは一切ありません。**「データは収集されません（Data Not Collected）」**を選べるはずです。

| データの種類 | 収集する？ | 備考 |
|---|---|---|
| 写真 | しない（開発者への送信なし） | 端末内IndexedDBにのみ保存 |
| 氏名・メールアドレス等の個人情報 | しない | アカウント機能自体が無い |
| 位置情報 | しない | - |
| 連絡先 | しない | - |
| 閲覧履歴・広告用データ | しない | - |

**補足**：設定画面でapi-sports.ioの任意のAPIキーを登録した場合のみ、「試合結果をAPIから取得」機能で対戦相手・日付の検索条件がapi-sports.ioへ送信されます。開発者は関与しない、利用者自身が選んで使う外部サービス連携のため、申請時の質問で「サードパーティとのデータ共有」について聞かれた場合はこの点を正直に回答してください（デフォルトでは無効・未使用の機能です）。

「トラッキングに使用」は**いいえ**。

## スクリーンショットについて

実機・シミュレータ、またはNode.js + Playwrightでの自動撮影で、実際の画面のスクリーンショットを用意してください（6.5インチ・6.7インチクラスの解像度が必須になることが多いです。要件は申請時の画面で確認してください）。一覧画面（試合カード）・選手分析画面・記録フォームなど、実際の画面内容を反映したものにしてください。
