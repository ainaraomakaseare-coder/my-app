# たびログ

旅行の思い出を、写真とともに「日ごと・時間ごとのモデルコース」として振り返るアプリです。いつからいつまで・だれと・どこへ・どこに泊まって・いくらかかって・楽しかったかを、るるぶの旅行ガイドやPolarstepsのような時系列の記録としてまとめます。

```
open index.html
```

**このアプリは、これまでのDAY（NHKチンチロ・輸入ブラックジャック・ドラマ王・人狼・おもいでWiki）と違い、保存先が端末の中（localStorage）ではなくサーバー（データベース）です。** 旅行のURLを家族に送るだけで、送られた側もその場で見たり書き足したりできます。かわりに `worker/README.md` の手順でサーバーを一度公開する必要があります。

## できること

- **旅行を作る**：タイトル・出発日〜帰着日・だれと行ったかを登録すると、日程から自動で「1日目」「2日目」…の日タブができます
- **日ごとのモデルコース**：選んだ日の記録を、時間順にタイムラインで並べます。番号つきのバッジ・写真・ひとことメモ・費用・楽しかった度（★）を1つのカードにまとめます
- **費用と評価**：記録ひとつごとに費用（円）と楽しかった度（★1〜5）を任意でつけられます。旅行全体の総費用も自動で合計します
- **宿泊の記録**：「種類」を「宿泊」にすると、そのカードだけ色を変えて「本日の宿」として目立たせます。旅行全体の宿泊先も一覧の上部にまとめて表示します
- **地図・公式サイト・予約サイト**：記録ごとにGoogleマップなどのURL、公式サイトのURL、予約したサイト名（任意のテキスト）を添えられます
- **別行動したメンバーのタグ**：「父・妹チーム」のように自由に書けるタグを記録につけると、あとでそのタグだけに絞り込んで見られます（全員が常に同じ行動とは限らないため）
- **共有して招待する**：旅行の詳細画面の共有ボタンで、今開いているURL（`?trip=旅行のID` を含む）をコピーできます。このURLを知っている人は誰でも見たり書き足したりできます（アカウント登録は不要です）
- **写真**：選んだ時点で自動的に縮小・圧縮してからサーバーへアップロードします（長辺1280px・JPEG品質72%程度）

## 共有の仕組みについて（重要）

このアプリにはログイン機能がありません。旅行ごとに発行される `trip_xxxxxxxx` というIDを含むURLを知っている人なら、誰でも読み書きできます（Googleドキュメントの「リンクを知っている全員が編集可」に近い方式です）。家族・少人数のグループでURLを送り合って使うことを想定した、簡易的な共有です。不特定多数に公開するような使い方はおすすめしません。

## サーバーについて

写真やデータの保存にはCloudflare WorkerとD1（データベース）・R2（写真の保存）を使います。公開手順・費用の目安（無料枠に収める方針）は `worker/README.md` を参照してください。**サーバーを公開して `index.html` の `tabilog-api-endpoint` メタタグにURLを設定するまでは、旅行の保存はできません**（トップ画面にその旨の案内が出ます）。

## 今回やっていないこと（見送った機能）

- メンバーの会話を音声で聞き取って過去の旅程を自動で作る機能（要望はあったが、今回は見送り、後日あらためて要件を詰めてから着手する）
- おもいでWiki（`apps/day18-omoide-wiki/`）にあるようなAIによる深掘りインタビュー・文章の自動整形（このアプリはAI呼び出しを持たない）
- 実際の地図表示（埋め込み地図はGoogle Maps APIの課金が発生しうるため、今回はURLを貼るだけの簡易的なリンクにとどめている）
