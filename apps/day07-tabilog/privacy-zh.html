旅の足跡 隱私權政策

最後更新日：2026 年 9 月 30 日

「旅の足跡」（以下稱「本 App」）是一款讓您與家人、朋友共享旅行紀錄的 App。本政策說明本 App 會取得、儲存哪些資訊，以及這些資訊的處理方式。

1. 取得的資訊

  • 登入所使用的資訊：以 Google、Apple 或 LINE 帳號登入時，我們會取得您的姓名（顯示名稱）與電子郵件地址。以 LINE 登入時，我們會取得 LINE 的顯示名稱；電子郵件地址不會從 LINE 取得，而是使用您首次登入時以驗證碼確認過的電子郵件地址。以電子郵件地址登入時，我們會取得您輸入的電子郵件地址。這些資訊僅用於自動填入「記錄者」欄位，以及將使用相同電子郵件地址登入的人視為同一個帳號。
  • 使用者輸入的資訊：旅行的標題、日程、參加者姓名；行程（大項目）的日期時間、標題、種類；紀錄（小項目）的心得、短評、詳細內容、花費明細、等待時間、照片、影片、店家或地圖的網址、記錄者的名字；對旅行或紀錄的按讚與留言。以上全部都是使用者自行決定輸入的內容。
  • 個人頭像：若你設定，個人頭像會被儲存並顯示在你的「我的頁面」（以及顯示你名字的相關畫面）。刪除帳號時，個人頭像也會一併刪除。

2. 資訊的儲存位置

您輸入的資訊（包含照片、影片）會儲存在 Cloudflare 公司的資料庫（D1）與儲存空間（R2）。除本 App 的開發者之外，我們不會將這些資訊販售或提供給任何第三方。我們也不會為了投放廣告而進行追蹤。

2-2. 關於付費與支付

本 App 目前沒有付費的功能、方案或次數券。所有功能都可以免費使用。因此，我們不會取得或儲存信用卡號等支付相關資訊。

3. 資訊的分享範圍

知道每趟旅行所發出的網址（邀請連結）的人，即使沒有登入，也能查看、編輯、刪除該趟旅行的內容（包含照片、影片）。請只將邀請連結傳給一起旅行的人等值得信任的對象。按讚、留言、使用 AI 匯入等部分功能，需要登入（電子郵件地址、Google、Apple 或 LINE 其中之一）。本 App 的設計前提是讓知道網址的人之間彼此分享，並不打算向不特定的多數人公開。對旅行或紀錄的按讚與留言，也會連同帳號名稱顯示給知道該旅行網址的人（不會顯示電子郵件地址）。不適當的留言可以檢舉，被檢舉的內容將由營運者確認，並視需要刪除。

4. 第三方服務

登入功能使用了 Google Identity Services（Google 登入）、Sign in with Apple（Apple 登入）以及 LINE 登入（LINE Yahoo 股份有限公司提供的登入）。使用這些服務時，也適用各公司的隱私權政策。

  • Google 隱私權政策：https://policies.google.com/privacy
  • Apple 隱私權政策：https://www.apple.com/legal/privacy/
  • LINE Yahoo 隱私權政策：https://www.lycorp.co.jp/ja/company/privacypolicy/

語音輸入、筆記整理、收據辨識、截圖匯入功能：使用「用語音、筆記一次記錄」功能時，錄下的語音資料與輸入的筆記文字；使用「辨識收據」功能時，收據的照片；使用「從截圖建立行程」功能時，您選取的截圖（圖片），為了辨識內容、轉成文字，會傳送給下列服務。我們不會傳送姓名、電子郵件地址等可識別使用者的資訊。首次使用這些功能時，App 內會顯示傳送對象的說明，並在取得您同意後才傳送（若不同意，就無法使用這些功能）。

  • 語音轉文字：會先嘗試以 Cloudflare, Inc. 的 Workers AI（在 Cloudflare 伺服器上運作的 AI 模型）轉成文字，只有在無法順利辨識時，才會把語音資料傳送給 OpenAI, L.L.C.（美國）的 API。另外，本 App 的紀錄資料（包含照片、影片）原本就儲存在 Cloudflare 公司的資料庫與儲存空間（D1、R2）（亦請參閱本政策第 2 條）。
  • 將語音轉出的文字、筆記的文字，整理成行程與紀錄：會將文字傳送給 OpenAI, L.L.C. 的 API。
  • 辨識收據：會先以 Google LLC 的 Cloud Vision API 辨識文字，只有在無法順利辨識時，才會把照片傳送給 OpenAI, L.L.C. 的 API。
  • 從截圖建立行程的功能：會將您選取的截圖（圖片）傳送給 Google LLC 的 Cloud Vision API 辨識文字，再將辨識出的文字傳送給 OpenAI, L.L.C. 的 API，整理成行程候選。候選中包含的地點名稱，為了查詢地圖上的位置，會傳送給 Google LLC 的地點搜尋。圖片本身不會儲存在本 App 中（只有您確認並儲存的行程內容，會作為紀錄資料儲存）。

依 OpenAI 的 API 使用條款，傳送的資料預設不會用於模型訓練。

  • Cloudflare 隱私權政策：https://www.cloudflare.com/privacypolicy/
  • OpenAI 隱私權政策：https://openai.com/policies/privacy-policy

地點搜尋、地圖、路線導覽：您在「以地點名稱搜尋」欄位輸入的文字，或貼在紀錄中的地圖連結裡的店名、地名，為了查詢地點候選與座標，可能會傳送給下列服務。無論哪一項，都不會傳送帳號資訊（姓名、電子郵件地址等）。

  • Google LLC（Google Maps Platform）：以 Places API 搜尋地點、取得座標，以 Routes API 取得電車、新幹線等的轉乘導覽（路線上的座標）。https://policies.google.com/privacy
  • OpenStreetMap 的地圖圖磚、Nominatim（搜尋、反向查詢）：用於顯示地圖（由您的裝置直接載入圖磚圖片），以及從地點名稱搜尋座標。https://osmfoundation.org/wiki/Privacy_Policy
  • 維基百科、維基數據（Wikimedia Foundation）：用於輔助從設施名稱搜尋座標。https://foundation.wikimedia.org/wiki/Policy:Privacy_policy
  • routing.openstreetmap.de（OSRM）、BRouter（brouter.de）：用於計算開車、步行、騎自行車、搭電車的路線（路線上的座標）。
  • Open-Meteo：用於從地名搜尋座標（地理編碼），以及判斷當地時間。

花費的外幣換算：當您以外幣輸入花費明細時，為了取得匯率，只會將幣別代碼與日期傳送給 Frankfurter（api.frankfurter.dev）或 fawazahmed0/currency-api（由 jsDelivr 提供）。不會傳送姓名、電子郵件地址等資訊。

另外，「讓您自己使用的 AI 服務產生行程建議（JSON 格式）再匯入」的功能，是由使用者自行複製請求文字、貼到該 AI 服務，再把回傳的答案貼到本 App 的方式。本 App 不會傳送這些內容（使用時，適用該 AI 服務的使用條款）。

5. 資料的刪除

旅行紀錄可隨時透過 App 內的刪除功能刪除。與登入中帳號相關的資訊（名字、額外次數、與參加旅行的連結、按讚、留言），可隨時由您自行在「我的足跡」畫面的「刪除帳號」中刪除。此外，為了防止有人不當重複取得每月的免費使用次數，只有電子郵件地址與該月語音輸入的使用次數，會基於防止不當使用的目的而保留（即使以相同的電子郵件地址重新註冊，該月的使用次數也不會恢復）。若您希望連同電子郵件地址在內完全刪除，請透過下方聯絡方式與我們聯繫。

6. 關於兒童使用

本 App 的設計以家人共同使用為前提，但帳號的建立與登入，請在家庭的判斷與監護人的管理下進行。

7. 本政策的變更

本政策的內容可能視需要而變更。變更後的內容自刊載於本頁時起生效。
