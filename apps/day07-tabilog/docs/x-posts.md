# X（旧Twitter）の投稿案

旅の足跡の機能を1つずつ紹介する投稿の下書きです。機能ごとに分けてあり、1日1〜2本ずつ予約投稿する想定です。

- 本文はどれも140字以内です（URLはXでは23字と数えるので、LPのURLを付けても収まります）
- LP：`https://tabinoashiato.pages.dev/lp/`
- 画像は `lp/img/` の画面か、アプリの「動画でシェア」で作った動画を添えると伝わりやすいです
- ハッシュタグは `#旅の足跡` を共通にして、内容に合うものを1〜2個足します

## 1. はじめに（アプリ全体）

1. 旅行のあと「あれ、どこのお店だっけ？」ってなりませんか。旅の足跡は、写真・費用・ひとことを時間ごとに残して、一緒に行った人とみんなで書き足せる旅行記録アプリです。基本無料。#旅の足跡 #旅行記録
2. 家族旅行の思い出、写真フォルダに埋もれていませんか。「11:00 首里城」「12:30 沖縄そば」みたいに1日の流れで残しておくと、何年たっても旅をなぞれます。#旅の足跡 #家族旅行
3. 旅行記録アプリ「旅の足跡」でできること：時間ごとの記録／リンクで共有／地図でふりかえる／割り勘の精算／行った国・都道府県の集計。iPhoneはアプリ、Androidやパソコンはブラウザで。#旅の足跡

## 2. みんなで書き足す（共有）

1. 旅行のリンクをLINEに貼るだけ。受け取った人はアプリを入れなくても、ログインしなくても、その場で見たり書き足したりできます。#旅の足跡 #家族旅行
2. 写真はママのスマホ、お店のメモはパパ、感想は子ども。旅の記録は1人で書かなくていい。同じ旅行にみんなの記録が集まっていきます。#旅の足跡
3. 「午後だけ別行動」も、そのまま残せます。同じ予定の下に記録を分けたり、ひとりだけの道を作ったり。あとから「その人の道」に切り替えて見られます。#旅の足跡

## 3. 日ごとのきろく（写真・動画・費用・評価）

1. 予定ごとに、写真・動画・ひとこと・費用をまとめて残せます。並べると、それだけで旅の1日のアルバムに。#旅の足跡 #旅行記録
2. 費用は明細ごとに入れると自動で合計。旅行全体の総費用もすぐ出ます。「この旅、結局いくらだった？」に一発で答えられます。#旅の足跡 #旅行費用
3. 行ったお店・宿・スポットに★1〜5をつけられます。一緒に行った人もそれぞれ★をつけられて、旅行の中では平均点で表示。#旅の足跡 #グルメ記録
4. 宿泊先は「1〜2泊目はこの宿、3泊目は同上」のように夜ごとに整理。旅の上に宿泊先と総費用がまとまって出ます。#旅の足跡

## 4. 地図でふりかえる・動画でシェア

1. 記録した場所をつないで、旅の足跡が地図の上を走り出します。電車は線路に沿って、飛行機は空を越えて。着いた場所では、その時の写真が出てきます。#旅の足跡 #旅の思い出
2. 「地図でふりかえる」をタイムラプスみたいに再生すると、自分たちの旅を空から眺めている気分になります。旅行から帰った夜に、家族でぜひ。#旅の足跡
3. ふりかえりの地図を、そのまま縦長の動画にできます。ストーリーズやTikTokに旅のダイジェストを載せたいときに。#旅の足跡 #旅行動画
4. 日帰りなら約30秒、長い旅でも45秒以内。動画には地名と日付が出て、費用や同行者の名前は入りません（写真を入れるかは選べます）。#旅の足跡

## 5. まとめて取り込む（スクショ・声・メモ・レシート）

1. 航空券・ホテル予約・新幹線のきっぷのスクショを最大10枚選ぶだけ。AIが日付と時刻ごとの予定に分けてくれます。確認してから追加するだけ。#旅の足跡 #旅行準備
2. 旅のあと、今日あったことを話すだけで記録になります。話した順に予定と記録に分けて保存。書くのが面倒な日でも続けられます。#旅の足跡
3. メモ帳に書いた旅程を貼り付けるだけで、予定にまとめて取り込めます。書いていないことは推測で埋めないので、あとから安心して直せます。#旅の足跡
4. レシートを撮ると、品目と金額を読み取って費用の明細に入れてくれます。旅先でレシートが財布にたまっていく問題、これで解決。#旅の足跡 #旅行費用

## 6. 割り勘・精算

1. 旅行の割り勘、帰ってから計算していませんか。費用ごとに「払った人」と「割る人」を選んでおくだけで、だれがだれにいくら払えばいいかまで出します。#旅の足跡 #割り勘
2. 精算は、送金の回数がいちばん少なくなる組み合わせで出します。端数は1円・10円・100円単位で丸められるので、現金でも払いやすい。#旅の足跡 #割り勘
3. 海外で払った分は外貨のまま入れればOK。その日のレートで円に換算して、ほかの費用と一緒に精算できます。#旅の足跡 #海外旅行

## 7. マイログ・行ったことある旅先

1. 行った都道府県が、日本地図に塗られていきます。参加した旅行の記録から自動で集計するので、入力はいりません。全国制覇まであと何県？ #旅の足跡 #47都道府県
2. 海外の旅先は世界地図に。「アメリカ」と「アメリカ合衆国」は同じ国にまとめて、乗り継ぎで寄っただけの国は数えません。#旅の足跡 #海外旅行
3. ★をつけたごはん・宿・アクティビティは、旅をまたいで「飯ログ」「ほてログ」に。自分だけに見えるので、正直な★でOK。#旅の足跡 #グルメ記録

## 8. 海外旅行

1. 海外旅行の記録で困るのが時差。旅の足跡は地図の場所から現地の時刻で並べて、時差が変わるところに区切りを入れます。#旅の足跡 #海外旅行
2. 日付変更線をまたぐ旅（東京→ロサンゼルスなど）も、地図でふりかえるとちゃんと太平洋を越えていきます。#旅の足跡 #海外旅行
3. 乗り継ぎで立ち寄っただけの国は、マイログの「行った国」に数えません。違っていたら、タップしてどの旅から入ったかを見て外せます。#旅の足跡

## 9. 料金・安心

1. 旅の足跡は基本無料。記録・共有・地図でふりかえる・精算・マイログは回数の制限なく使えます。AIの取り込み（声・メモ・スクショ）だけ、毎月10回までです。#旅の足跡
2. 旅行の記録は、その旅行のリンクを知っている人だけが見られる仕組みです。一緒に行った人どうしで送り合ってください。#旅の足跡
3. ログインが要るのは、★評価とマイログを使うときだけ。見る・書き足すだけならアカウントなしで使えます。#旅の足跡
