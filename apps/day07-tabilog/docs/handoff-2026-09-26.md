料金は2026-09-26に公式ページで確認した。どちらも請求先アカウント（カード）の登録が必須。

| Places API (New) | Autocomplete Session Usage | 無制限 | ― |
| Cloud Vision | DOCUMENT_TEXT_DETECTION | 月1,000枚 | $1.50/1000 |

### ユーザーにお願いする準備（画面ごとに案内すること）
1. Google Cloudでプロジェクトを作り、請求先アカウントを登録する。
2. 「Places API (New)」と「Cloud Vision API」を有効にする。
3. APIキーを作り、使えるAPIをこの2つだけに制限する。
4. クォータで1日の上限を設定し、無料枠を超えないようにする。例：Autocomplete 300/日、Place Details 300/日、Vision 30/日。予算アラートも設定する。
5. `npx wrangler secret put GOOGLE_API_KEY` を実行してもらう（キーをコードやGitHubに書かない）。

### 作り方（キーが無い・上限に達した・エラーのときは、今の仕組みに自動で戻す）

**場所の候補**（Worker の `searchPlaces`、`GET /places/search`）
- `POST https://places.googleapis.com/v1/places:autocomplete`
  - ヘッダー：`X-Goog-Api-Key`
  - 本文：`{ input, languageCode: "ja", sessionToken }`
- 候補は `suggestions[].placePrediction` の `placeId`・`structuredFormat.mainText.text`（名前）・`secondaryText.text`（住所）。
- 座標は返らないので、候補に `placeId` を持たせて返す。
- 「選択」したら新しい `GET /places/details?id=...&session=...` を呼ぶ。
  - 中で `GET https://places.googleapis.com/v1/places/{id}` を呼ぶ。
  - ヘッダー：`X-Goog-FieldMask: location,displayName,formattedAddress`（Essentials の範囲に収めること。Pro のフィールドを足すと有料枠が変わる）。
  - `sessionToken` を付ける。
- クライアントの対象
  - `app.js` の `showPlaceMapPreview`・`renderPlaceCandidates`・`choosePlaceCandidate`・`selectedPlace`・`previewSelectedPlace`・`useSearchedPlaceAsMapUrl`（4100行あたり）。
  - 候補に座標が無い（placeIdだけの）ときは、選択時に details を取ってから地図を出す。
  - sessionToken は検索を始めるたびに1つ作る（`crypto.randomUUID()`）。
- 地図URLは今までどおり `https://www.google.com/maps/search/?api=1&query=緯度,経度` に座標を入れる（ふりかえりが座標をそのまま使えるため）。`&query_place_id=` を足してもよい。
- 既存の Nominatim・ウィキペディア・空港の候補は、キーが無いとき、またはGoogleが失敗したときの予備として残す。

**レシート**（Worker の `scanReceipt`、`POST /receipts/scan`。2580行あたり）
- `POST https://vision.googleapis.com/v1/images:annotate?key=...`
  - 本文：`{ requests: [{ image: { content: base64 }, features: [{ type: "DOCUMENT_TEXT_DETECTION" }], imageContext: { languageHints: ["ja"] } }] }`
- 返ってくる `fullTextAnnotation.text` を行ごとにルールで分ける。
  - 行末の金額（`¥`・`￥`・`円`・カンマ付き数字）を拾う。
  - 合計・小計・税・内税・外税・お預り・お釣り・釣銭・値引・ポイント・点数・カードの行は除く。
  - 合計の値も返す。
- 分ける処理は Core（`app.js` 上部の純粋関数）か Worker に置き、`test/data.test.js` にテストを足す。
- 返す形は今の `receiptItemsSchema()` と同じにする。そうすればクライアント側（`app.js` 1643行 `scanReceiptBlob`、4070行あたり）はほぼそのまま使える。
- Visionで読むときは回数の枠（`checkVoiceQuota`）を使わない。無料プランでも使えるようにし、ログイン必須もやめるか検討する。
- `AI_RATE_LIMITER` は残す。
- キーが無いときは今のOpenAIの処理（音声と共通の枠）のまま。
- 文書も直す：`CONTEXT.md` のレシートの節、`worker/README.md`、新しいADR（`docs/adr/0011-google-places-and-vision.md`）。
