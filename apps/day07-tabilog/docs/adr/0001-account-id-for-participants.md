# 参加者の紐付けに、メールアドレスではなく6桁のアカウントIDを使う

マイログに「参加した旅行一覧」を追加するにあたり、旅行の参加者（companions）とログイン中のアカウントを紐付ける必要が出てきた。既存の評価（ratings）・マイログは`rater_email`（生のメールアドレス）をそのままキーにしているが、参加者一覧はTripを共有された人なら誰でも見える画面なので、そこに生のメールアドレスを載せると新たな漏洩経路になる。そのため参加者の紐付けだけは、アカウント作成時に発行する6桁の数字（アカウントID）を使うことにした。ratings/マイログのメールアドレスキーは今回変更しない（別の弱点として`CONTEXT.md`に既存の記載がある）。
