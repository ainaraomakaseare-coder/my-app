# 時系列ムービー（写真と動画を時間の順に流す縦動画）

オーナー要望（2026-10-19）：「地図としての振り返りはあるけど、単純にこの時間に何をしたかを、写真や動画と時間でつなげた動画を作りたい」「動画も入れたい」。

**決めたこと**：
- 旅行の画面に「時系列ムービーを作る」ボタンを置き、専用のシートで作る。地図でふりかえる・動画でシェア（ADR 0020）のコードは変えず、録り方（canvas.captureStream＋MediaRecorder）と、画像の読み込み・並列処理・画面に戻るまで待つ関数だけを使う。
- 絵コンテは純粋関数`Core.buildTimelineStory`（`test/data.test.js`でテスト）：表紙→日の区切り→予定ごとの写真（2枚まで、1.8秒）と動画（1本まで、4秒）→終わり。720×1280・30fps。60秒を超えるときは、予定ごとの写真を1枚にし、それでも長ければ予定を均等に間引く（最初と最後は残す）。「動画に出さない」予定（videoExclude）は入れない。
- 画面に出すのは日・時刻・予定の見出しと写真・動画だけ。費用・日記の文章・人の名前は入れない。
- 動画の音は入れない（複数の音を混ぜる仕組みが要り、同行者の声が入ることもあるため）。
- 読み込めなかった写真・動画、CORSが通らずcanvasを汚す動画は外して作り直す。

**Workerの変更は無し**。
