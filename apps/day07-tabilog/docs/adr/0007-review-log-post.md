# 紹介文（ホテログ・レクログ・飯ログ）を記録から作る

旅の紹介動画（「5泊7日の総額公開！」のような縦型動画。ホテル・食事・観光ごとに★と◎〇△の評価を重ね、最後に合計金額を出す）の文字の部分を、アプリの記録から作れるようにしたい、という要望があった（2026-09-25）。インフルエンサーに旅を発信してもらう入口（docs/adr/0006の次の段階）にもつながる。

**決めたこと**：
- 予定の種類でログの種類が決まる：宿泊→**ホテログ**、食事→**飯ログ**、観光・その他→**レクログ**、移動→**移動**（★なし）
- ★とレビュー項目は**一人ひとりが自分の分を書く**。既存の評価（ratingsテーブル、人ごとに1件）に`review`（JSON）を足す形にし、★の仕組みを二重にしない。★は押した瞬間に保存、レビュー項目は「レビューを保存」で★と一緒に保存する（★だけの更新ではレビュー項目を消さない）
- ★の言葉は種類ごとに変える（例：ホテル 4.5〜 絶対また泊まりたい／4.0〜 また泊まりたい／3.5〜 また泊まってもいい／3.0〜 機会があれば泊まる）
- **★3.0ちょうどは紹介文に出す、3.0未満は出さない**（「3.0 機会があれば行く」の言葉を活かすため。要望の「3.0以下は公開しない」と重なっていたので確認して決めた）
- 移動は★をつけず、区間・会社/便名・出発/到着・料金を**記録そのもの**（entries.travel）に持つ。誰が見ても同じ事実なので人ごとにしない。所要時間は出発・到着から計算（日をまたげば翌日とみなす）
- 移動手段に「車（レンタカー）」を足し、「タクシー」は「タクシー（Uber）」と表示する
- 金額はできるだけ既存の「費用の明細」を使う（ホテルの合計、飯ログのメニューと金額）。レビューに金額を入れればそちらを優先。泊数・回数・人数を入れると「1泊あたり／〇泊合計」のように出す
- 出力は、まず**コピーしてSNSに貼れる文章**。表紙（タイトル・日程・泊数・行き先の国/都道府県）→評価の基準（使った種類だけ）→時系列のログ→合計金額（移動・ホテル・食事と観光）。文章はシート上で直してからコピーできる

**補足した項目**（要望の項目に、参考動画やほかの紹介投稿でよく見るものを足した）：価格見合い（コスパ）、ホテルの清潔さ・朝食・部屋タイプ、レクの所要時間・おすすめの時間帯・予約（不要/推奨/必須）・混雑、飯の美味しさ・待ち時間（既存の欄）・おすすめメニュー、移動の区間・会社/便名

**見送ったこと・次の段階**：動画に重ねる画像カード（白い吹き出し）の書き出し、投稿の公開ページ。公開ページを作るときは、今は旅行を開いた人全員に評価した人のメールアドレス（ratings.rater_email）が返っている点を先に直す（docs/adr/0005の「移行後にやること」）。
