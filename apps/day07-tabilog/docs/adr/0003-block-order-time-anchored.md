# Blockの並び順は「時刻ありは時刻固定、時刻なしはドラッグで自由」にする

「出来事の前後関係を変えたいときに場所を変えたい、引っ張って感覚的にできるといい」という要望を受け、Block（予定）をドラッグで並べ替えられるようにする際、既存の並び順ルール（両方のBlockに時刻があるときだけ時刻で比べ、どちらか一方でも未設定なら作成順で比べる：DAY7の音声入力対応で追加）とどう共存させるかを決める必要があった。

選択肢は2つ。①時刻ありのBlockは常にその時刻の位置に固定し、ドラッグできるのは時刻未設定のBlockだけにする。②ドラッグの並び順を常に優先させ、時刻はあくまで表示用の情報として扱う（時刻を入れても自動では並び替わらなくなる）。ユーザーに確認したところ①を選んだ。

①を採用したため、時刻が入っているBlockにはドラッグの持ち手（`.block-drag-handle`）自体を出さない。時刻未設定のBlockは、時刻ありのBlockの前後にも自由に差し込める（並び順の比較は既存のルールのまま、時刻未設定同士・時刻あり×時刻なしの組はcreated_atで比較するため）。ドラッグ確定時は、その日のBlock全部のcreated_atを新しい見た目の順番で振り直すAPI（`PATCH /trips/:id/days/:date/blocks/reorder`）を新設した。時刻ありのBlock同士の順番は、時刻そのものを変えない限り変わらない。
