# 友達同士のいいね・コメント（SNS機能の第一段階）

旅の紹介を発信してもらい、インフルエンサー経由でアプリの利用者を増やしたい、という要望があった（2026-09-25）。公開プロフィール・フォロー・公開された旅の一覧まで一度に作ると大きすぎるうえ、Appleの審査（ガイドライン1.2：ユーザーが投稿したものを他の人が見られるアプリ）への対応も要るため、**まずは友達同士（旅行のリンクを共有している人同士）でいいね・コメントをし合えるところから始める**ことにした。

**決めたこと**：
- 対象は**旅行と記録（Entry）の両方**。旅行詳細の上部と、各記録カードの下にボタンを出す
- 読むのは旅行のリンクを知っている人なら誰でも（旅行そのものの共有範囲と同じ）。**書く（いいね・コメント・通報・ブロック）にはログインが必要**で、セッショントークン（docs/adr/0005）を必須にする（古いメールアドレスだけの方式は受け付けない）
- 書いた人は`account_id`で持ち、表示名は`accounts.name`から引く。他人にメールアドレスは見せない
- コメントは画面を切り替えず、下から出るシートで読み書きする（タイムラインの位置が保たれるように）
- 自分のコメントだけ削除できる。旅行・予定・記録・アカウントを削除したら、ぶら下がるいいね・コメントも消す

**Appleの審査ガイドライン1.2のために入れたもの**：
- 不適切な投稿を防ぐ仕組み：明らかな暴言・差別語を含むコメントはサーバーで保存しない（`BANNED_WORDS`。完全な判定は無理なので見逃しは通報・ブロックで補う）
- 通報：通報した本人にはそのコメントが見えなくなり、`REPORT_NOTIFY_EMAIL`（Workerのvars）宛にResendでメールが届く。運営者は24時間以内に確認し、必要ならD1から削除する
- ブロック：ブロックした相手のコメントは、自分には見えなくなる
- 初めてコメントするときに、ルール（不適切な投稿の禁止・違反時は削除や利用停止）への同意を求める

**次の段階（未着手）**：公開範囲（非公開／リンクを知っている人だけ／公開）の設定、公開プロフィール、フォロー、公開された旅の一覧、XやInstagramに共有したときのプレビューカード（OGP）。公開を始める前に、`REQUIRE_SESSION`をオンにできている（古いアプリが使われていない）ことを確認する。
