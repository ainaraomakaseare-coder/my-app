# 写真の撮影場所を記録の地図に入れる

競合調査（Polarstepsなど）で「GPSで道のりを自動で記録する」機能が旅の足跡に無いと分かった。ただ、ずっと位置を取り続けるのは審査・電池・プライバシーの面で嫌がられやすいため、オーナーと相談して「写真の位置情報から道のりを作る」方針にした（2026-10-19）。

**決めたこと**：
- 記録に写真を追加したとき、**地図欄がまだ空なら**、最初に位置情報のある写真の撮影場所を「現在地を入れる」と同じ形（座標の地図URL＋ピンを動かせる地図）で入れる。自分で地図を入れた・検索欄に入力した記録は変えない。地図でふりかえるの道のりは記録の地図から作るので、そちらのコードは触らずに道のりが写真の場所を通るようになる。
- **iPhoneアプリ**：写真をファイルとして選ぶと、iOSが位置情報を消してしまう（WebKitの仕様）。そのため「写真を追加する」は`@capacitor/camera`の`pickImages`で写真ライブラリから直接選び、返ってくる`exif.GPS`（`Core.gpsFromExif`）を使う。初回に写真ライブラリへのアクセス許可を聞く（Info.plistの`NSPhotoLibraryUsageDescription`はCIで追加）。
  - カメラで撮る・ファイルから選ぶは、その下の小さいボタンからこれまでどおり選べる。
  - アクセスを断られたら、次からはこれまでどおりの選び方（場所なし）にする。
  - 「選んだ写真だけ許可」の場合、選んだ写真が許可の範囲外だと場所は読めない（写真は追加される）。
  - プラグインの入っていない古いアプリ（1.4.0まで）は、これまでどおりの選び方のまま。
- **ブラウザ（パソコンなど）**：JPEGのExifから直接読む（`Core.jpegGpsFromBuffer`、先頭256KBだけ読む）。HEICは読まない。
- 0,0や範囲外の値は場所として使わない。

**避けたこと**：バックグラウンドでのGPS記録。撮影時刻から記録の時刻を自動で入れること（今回は場所だけ。必要になったら同じ仕組みで足せる）。

**Workerの変更は無し**。iPhoneに届けるには新しいビルドが要る。

**2026-10-31 追記（変更）**：記録を追加の写真は、iPhoneアプリでもネイティブの写真選び（pickImages）をやめ、動画と同じふつうのファイル選択にした。写真ライブラリへ直接行くとカメラで撮れず、利用者が「写真ライブラリ／写真を撮る／ファイルを選択」が出る形を望んだため。代わりに、iPhoneアプリで記録に写真を追加しても撮影場所は入らないことがある（ファイルとして渡すと位置情報が消えるため）。「写真から旅程を作る」は引き続きネイティブの写真選びで場所を読む。
