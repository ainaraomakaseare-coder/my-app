# 音声からの記録作成は、下書き確認を挟まず直接保存する

旅の足跡はこれまでAIを一切呼び出さないアプリだったが、「音声で話した内容を複数の予定・記録に自動分割する」機能の追加にあたり、初めてAI（OpenAI）呼び出しを導入する。ユーザーに「保存前に下書きを確認する画面を挟むか、直接保存するか」を確認したところ、直接保存（あとから普通の編集画面で直す）を希望された。AIの解釈がずれても、既存の編集・削除機能で十分にリカバリーできると判断したため、確認画面は作らない。あわせて、日付・時間帯の判定もAIにはさせず、常に「今開いている日タブ」に固定する（時刻順ではなく、話した順番で並べる）。評価・費用明細などAIに推測させると事実と異なりやすい項目は、今回のスコープに含めない。
