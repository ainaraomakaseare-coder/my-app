# 音声からの記録作成は、下書き確認を挟まず直接保存する

旅の足跡はこれまでAIを一切呼び出さないアプリだったが、「音声で話した内容を複数の予定・記録に自動分割する」機能の追加にあたり、初めてAI（OpenAI）呼び出しを導入する。ユーザーに「保存前に下書きを確認する画面を挟むか、直接保存するか」を確認したところ、直接保存（あとから普通の編集画面で直す）を希望された。AIの解釈がずれても、既存の編集・削除機能で十分にリカバリーできると判断したため、確認画面は作らない。あわせて、日付の判定もAIにはさせず、常に「今開いている日タブ」に固定する（話した順番で並べる）。評価などAIに推測させると事実と異なりやすい項目は、今回のスコープに含めない。

**追記（2026-09-14）**：時刻（Block.time）と費用の明細（Entry.costItems）は、当初「AIに推測させると事実と異なりやすい」としてスコープ外にしていたが、「話されたときは入れてほしい」という要望を受けて範囲を広げた。ただし判定基準は変えていない＝**話されていないことを推測で埋めない**のは変わらず、「明確に話された時刻・金額だけをそのまま拾う」形にとどめている（プロンプトで明示）。評価（★）は本人が押す行為に意味があるため、引き続きスコープ外のまま。
