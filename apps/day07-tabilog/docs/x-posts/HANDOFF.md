# X投稿の予約をお願いするセッションへ

旅の足跡（旅行記録アプリ）の機能紹介を、Xに予約投稿してください。このファイルだけ読めば作業できるように書いています。

## やること

1. `posts.json` の `posts` を、`scheduled_at` の日時（日本時間）で1件ずつ予約投稿する（全29件）
2. `image` が入っている投稿は、そのURLの画像をダウンロードして添付する（空なら画像なし）
3. 予約が終わったら、予約できた件数と、予約できなかった投稿（あれば理由）をオーナーに報告する

## 守ること

- **本文は変えない。** 誤字に気づいたら、直さずにオーナーへ報告する（言い回し・絵文字・ハッシュタグ・改行もそのまま）
- **`on_hold` の 9-1 は予約しない。** AIの無料枠の回数が本番で切り替わるまで保留。オーナーから指示があったら、本文の `{N}` を指示された回数に置き換えて予約する
- 予約の日時は日本時間（`+09:00`）。予約ツールが別のタイムゾーンで動いているときは換算する
- 1件の長さはXの数え方（日本語・絵文字は2、URLは23）で280以内に収めてある（`weighted_length`）。ツールが長すぎると言ったら、本文を削らずにオーナーへ報告する
- すでに同じ本文の投稿・予約があれば、二重に予約しない

## ファイル

| ファイル | 中身 |
|---|---|
| `posts.json` | 予約に使うデータ。`posts[]`：`no`・`id`・`category`・`scheduled_at`・`text`・`image`・`weighted_length`。`on_hold[]`：保留中の投稿 |
| `posts.csv` | `posts.json` の `posts` と同じ内容の表（ツールにCSVで読み込ませたいとき用） |
| `README.md` | 人が読むための一覧（日付・本文・画像） |
