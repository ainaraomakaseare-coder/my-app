# 企画を決める（分析部隊の③）

判断の仕事なので、サブエージェントに渡さず、この会話（Opus）で決める。
下書きの点検やネタの重複確認のような機械でできる確認は、コードで行う。

## 先に読むもの
1. `docs/research/README.md`（分析部隊の決まり）
2. `research/<genre>/<date>-analysis.md`（分析の結果）
3. `CLAUDE.md`（嘘を書かない・お金をかけない・PR表記）
4. genre ごとの前提
   - `ai`：ひろや｜AI初心者30日30アプリ。本人の実践記録（点検は `personal`）。**目的はフォロワー**
   - `career`：転職のホンネまとめ。口コミを集めるキュレーター（点検は `curator`、一人称の体験は禁止）。A8.net の案件あり。X には案件リンクを載せない

## 決め方
1. 分析の「需要と供給」「自分との比較」から、**変える点を3つまで**選ぶ。選んだ理由は分析の該当箇所（件数・URL）で示す。分析に無い根拠は使わない
2. 企画案を3つ作り、それぞれに書く
   - 狙い（genre の目的にどう効くか）
   - 根拠（分析のどの事実・どの投稿か）
   - 型（冒頭・長さ・形式・最後の呼びかけ）
   - **作れるか**：アプリで自動で作れるのは「文字の穴埋め6問の動画（720×1280・16.8秒）」と文章（Threads・X）だけ。顔出し・画面収録・声は人手になる。人手なら、1本あたりの手間を書く
   - お金：追加でかかるものがあれば、はっきり書いて利用者に相談する（勝手に採らない）
   - 確かめ方：何本・何日出して、何の数字を見て、どうなったら続ける／やめるか。いまは数字が小さく偶然の差が大きいので、**「のび率」と「保存・コメント」を、同じ型を最低10本出してから**見る
3. 3つのうち1つを推す。推す理由と、捨てた2つの理由を1行ずつ
4. 推した企画で、ネタを20本作る
   - `lib/topic-generate.js` の `screen()` に通して、重複・一人称・断定・出典のない数字を落とす（`node -e` で実行し、結果を plan に貼る）
   - 使ったネタとの重複は `public/topics.json` と過去の投稿の題名で見る
5. そのうち2本は、投稿案（動画の6行・Instagram・TikTok・Threads・X の本文）まで書き、`lib/draft-rules.js` の `validateDraft(draft, profileFor('<personal|curator>'))` に通す。error が0件になるまで直す

## 出力：research/<genre>/<date>-plan.md
1. `## 推す企画（1つ）`
2. `## 変える点と根拠`
3. `## 企画案3つの比較`
4. `## ネタ20本`（「まとめて仕込む」の欄にそのまま貼れる、1行1本）
5. `## 投稿案2本`（点検の結果つき）
6. `## 確かめ方と、やめる基準`
7. `## 利用者に決めてほしいこと`（お金・人手・アカウントの方針）

## 利用者への返事
推す企画を1段落、ネタ20本はファイルの場所を示す。**利用者が「これで行く」と言うまで、予約も投稿もしない。**
